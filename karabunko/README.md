# 空文庫（からぶんこ）

青空文庫から青が抜けて、空（から）の書庫だけが残った——という設定の、カオスで、絶望的で、ひとりきりのホラー・テキストアドベンチャー。
書庫の地下を、ランプ一つで最下層まで降りていく。

- ファイル：`karabunko.html`（HTML 一枚。外から読みこむのは DotGothic16 フォントと、青空文庫の本文）、`make-local.py`（手もとの青空文庫から棚を作る。任意）
- 操作：「空欄」「野帳」と同じ（状態行・「命令を作る」・十字キー・よく使う6ボタン・≡ メニュー・自動保存）
- 文章：ゲームの地の文は書き下ろし。床に落ちている「頁」と、棚の向こうから返ってくる声は、青空文庫の本物の文章

## 青空文庫の本文の取り方

遊ぶたびに、スマホのブラウザが GitHub の青空文庫リポジトリ（[aozorabunko/aozorabunko](https://github.com/aozorabunko/aozorabunko)）から直接読みにいく。

1. 目録：`index_pages/list_person_all_extended_utf8.zip`（作家別作品一覧の CSV）を取り、ブラウザの中で zip をほどく。著作権の切れた作品（作品著作権フラグ「なし」）だけを使う。目録は 30 日間、端末に残す。
2. 本：階を降りるたびに、目録から本を一冊（＋まぎれこむ本を一、二冊）選び、`cards/…/files/…html`（Shift_JIS の XHTML）を取る。ルビ・注記・外字の画像は取りのぞく。
   - 怪談・幻想寄りの書き手（夢野久作・岡本綺堂・泉鏡花・江戸川乱歩・芥川龍之介・梶井基次郎・小泉八雲・田中貢太郎など）の本が多めに出るが、それ以外の本もまぎれこむ。
   - 長い本は、「死・闇・夜・影・声・独り……」の字がいちばん多いあたりを切り出して使う。
3. 取ってきた本は、14 冊まで端末に残す。電波がないときは、残っている本だけで遊べる。一冊もないときは、このゲームのために書いた白紙に近い頁で遊ぶ（そのことは画面に出る）。

使われた頁が何という本の、誰の文章かは、「読む」で出る（例：「──『作品名』著者（19xx年に死去）」）。

### つながるかを Termux で確かめる

```sh
curl -sI https://raw.githubusercontent.com/aozorabunko/aozorabunko/master/index_pages/list_person_all_extended_utf8.zip | head -1
```

`HTTP/2 200` と出れば、ゲームからも取れるはず。

## 手もとの棚（Obsidian の Vault2 から）

スマホの `/storage/emulated/0/Obsidian/Vault2` にある青空文庫の全文から、ゲーム用の棚ファイル `karabunko-local.js` を作れる。
これを `karabunko.html` と同じフォルダに置くと、ゲームは GitHub に取りに行かず、手もとの本だけで遊ぶ（電波がいらない）。

Termux で次を貼りつけて実行する。

```sh
cat > ~/karabunko-shelf.sh <<'EOF'
cd ~/Claude
git fetch origin ccr-e757ea96-4yc97j
git checkout ccr-e757ea96-4yc97j
git pull origin ccr-e757ea96-4yc97j
python karabunko/make-local.py /storage/emulated/0/Obsidian/Vault2 /storage/emulated/0/Download
cp karabunko/karabunko.html /storage/emulated/0/Download/
EOF
sh ~/karabunko-shelf.sh
```

- 読むのは `.txt`・`.md`・`.html`。青空文庫らしいもの（「底本：」「青空文庫」を含む、ルビ《》や注記［＃］がある）だけを使い、ふつうのメモは読まない。`.obsidian` などの隠しフォルダも読まない。
- 青空文庫のテキスト形式（題名・著者・記号の説明・本文・底本）、Markdown の前置き（`title:`・`author:`・`没年:` など）、青空文庫の XHTML に対応する。ルビ・注記・外字の説明は取りのぞく。
- 棚に並べるのは 100 冊まで（怪談寄りの書き手が 7 割）。一冊から 250 文。もう一度走らせると、棚の本が入れかわる。
- 没年はファイルに書いてあればそれを使い、なければ主な書き手の没年の表から引く。どちらにもなければ「没年不明」。
- 終わると、見つけた本の数と、多い書き手が表示される。0 冊なら、ファイルの形が想定と違う。

Tasker で開くときは、`karabunko-local.js` も `/storage/emulated/0/Tasker/karabunko/` にコピーする。

## 遊び方

1. スマホのブラウザ、または Tasker のシーン（WebView）で `karabunko.html` を開く。最初の一回は電波のある場所で。
2. 名前を書いて「決定」（書かなくてもいい）。
3. 「命令を作る」→ 動詞 → 言葉（物）の順にタップする。入力欄に日本語で書いてもよい（例：`北`／`雨戸を拾う`／`雨戸を書く`／`燃やす`／`呼ぶ`）。
4. 困ったら「わからない」。

### Tasker で開く

```sh
mkdir -p /storage/emulated/0/Tasker/karabunko
cd ~/Claude
git fetch origin ccr-e757ea96-4yc97j
git checkout ccr-e757ea96-4yc97j
cp karabunko/karabunko.html /storage/emulated/0/Tasker/karabunko/
```

ほかのゲームと同じようにシーンを作り、WebView の Source を `file:///storage/emulated/0/Tasker/karabunko/karabunko.html` にする（Mode は `URI`。Allow Phone Access と Allow Universal Access はオン）。

### Tasker を使わずに開く

Download フォルダに `karabunko.html` を置いて、Termux で次を実行してから、Chrome で `http://localhost:8000/karabunko.html` を開く（遊んでいるあいだは Termux を閉じない）。

```sh
cd /storage/emulated/0/Download
python3 -m http.server 8000
```

## 音と演出

- 音はブラウザの中で作っている（音声ファイルは使わない）。画面に最初に触れたときから鳴る。≡ メニューの「音と振動」で切れる。
- 低いうなり（暗いほど大きい）、移動の紙をめくる音、×が近づくときの墨を引く音、頁を燃やす音、つかまったときの衝撃と振動。
- 灯が減るほど画面が暗くなり、灯が消えると字がほとんど見えなくなる。×が近いと画面が細かく震える。
- 深く降りるほど、暗いほど、×が近いほど、字が崩れる（漢字が ×・※・〓・自分の名前の字に化け、同じ字がくり返される）。

## 保存

- localStorage の `karabunko.state`。見た終わりは `karabunko.state.loop`（はじめからやり直しても残る）。
- 目録は `karabunko.catalog`、取ってきた本は `karabunko.works`。

| 項目 | 内容 |
|---|---|
| 階 | 地下一階〜地下六階、その下が最下層（奥付）。階ごとに部屋の並びも本も作りなおす。上り階段はない |
| 頁 | 部屋ごとに一枚。その階の本の数行。ときどき別の本の一文がまぎれこむ（深いほど多い） |
| 扉 | 各階の一番奥。扉の一文は、その階のどこかの頁の一文で、一語だけ □ になっている。その頁で抜けている言葉を「拾う」→ 扉の前で「書く」と開く。違う言葉は扉に飲まれる（ごくまれに、違っても開く） |
| 灯 | 動くたびに減る（深いほど速い）。頁を「燃やす」と 35 戻るが、その頁はもう読めない。答えの頁を燃やすと、扉の文が変わる。灯が消えて 10 手たつと終わり |
| ×（伏字） | 地下二階から。墨の線が部屋をめぐり、こちらへ寄ってくる（深いほど速い）。通った頁はところどころ×で塗りつぶされる。声を出す（呼ぶ・言う）と寄ってくる。「耳をすます」で方角がわかる。近いときに「隠れる」とやり過ごせる。つかまると名前が一字ずつ×になり、言葉を一つ失い、その階の最初の部屋に戻る。三度で終わり |
| 呼ぶ | 返事は、取ってきた本の「 」の中のことば。誰が言ったか（没年つき）が出る。返ってくるのは死んだ人の声だけ |
| 言葉 | 持てるのは五つまで。あふれると、いちばん古いものを忘れる |
| 記録 | ときどき、過去に打った命令が、打っていない命令に書き換わる |

終わり方は七つ。

- 入力済み：奥付に自分の名前を書く
- 青：奥付に「青」を含む言葉を書く（どこかの頁で拾っておく）
- 底本：奥付にそれ以外の言葉を書く
- 白紙：奥付を燃やす
- 校正待ち：奥付の前で待ちつづける
- 伏字：×に三度つかまる
- 消灯：灯が消えたまま歩きつづける

## 確認したこと

- このクラウド環境からは GitHub の青空文庫リポジトリにつながらなかったため、本物の青空文庫の本文ではまだ動かしていない。目録の URL・ブランチ名（`master`）・CSV の列名は、知っている形にあわせて書いた。
- かわりに、青空文庫と同じ形（zip に入った CSV 目録と、Shift_JIS の XHTML。ルビ・注記・外字の画像入り）の偽のリポジトリを作り、Chromium（スマホ幅 412px）で確かめた：
  - 目録の zip をほどいて読み、著作権ありの作品を外せること。本文の文字コードを読み分け、ルビ・注記が混ざらないこと
  - 取れない本（404）があっても次の本に移ること。リポジトリにつながらないときは白紙の棚で遊べること
  - 自動で遊ばせて、最下層まで降り、入力済み・白紙・校正待ち・伏字・消灯の終わりが出ること。青と底本は、最下層に置いて言葉を持たせた状態から出ることを確かめた
  - ボタンのランダム操作 2000 回で例外が出ないこと、開き直すと続きから始まること
- 手もとの棚：偽の Vault（青空文庫形式の Shift_JIS の txt、前置きつき Markdown、XHTML、ふつうのメモ、隠しフォルダ）で `make-local.py` を走らせ、青空文庫らしい 3 冊だけが拾われ、ルビ・注記が残らないこと。ゲームが localhost と file:// の両方でその棚を使い、GitHub に取りに行かないこと。
- 本物の Vault2 の中身は見ていない（このクラウド環境からは見えない）。ファイルの形が想定と違えば、本が 0 冊になる。
- 実機（Xperia 1 IV のブラウザ、Tasker のシーン）では、まだ確かめていない。
