# 星図ミニアプリ Astro（starmap）

Amazfit Balance 2（Zepp OS）で星空を見るミニアプリ。
時計をかざすと、その方向の星・惑星・月・太陽が出る（AR）。手首の上で星座盤のようにも見られる（MAP）。

曇りの日や昼間、室内など、実際の空が見えないときにも使えるようにした。

- 時刻をずらして、今夜や明け方の空を先に見る（時間移動）
- 方位磁針を使わず、指で見回す（TOUCH）
- 星座線を引く。北斗七星（おおぐま座）・カシオペヤ座・北極星も入れた

## 画面

```
        S 172°  +10°        ← 見ている方位と高さ（MAP では表示モードも）
      [ 10/07  21:00 ]      ← 時刻。タップで「次の21時」⇄「今」
[-1h]                [+1h]  ← 時刻を1時間ずつ動かす
          （星空）
  [MAP180] [SENSOR] [LIST]
```

| ボタン | 動き |
|---|---|
| 左下（AR / MAP90 / MAP180 / MAP360） | 表示の切り替え。AR は時計をかざして見る。MAP は上が向いている方向の星座盤で、数字は見せる方位の幅 |
| 真ん中（SENSOR / TOUCH） | 向きの決め方。SENSOR は方位磁針と傾き。TOUCH は指で動かす（オレンジ色） |
| 右下（LIST） | 太陽・月・惑星・星座・明るい星の方位と高さの一覧 |
| 時刻 | 灰色は今の時刻。オレンジ色は時刻をずらしているとき（止まった時刻） |
| -1h / +1h | 1時間ずつ戻す・進める（ちょうど○時00分にそろう） |

### 時間移動

- 時刻をタップすると、次の21時の空になる。昼間や夕方に「今夜どう見えるか」を見るとき用。
- もう一度タップすると今の時刻に戻る。
- -1h / +1h で1時間ずつ動かす。長押しで1日ずつ動く（はず。実機では未確認）。
- 時刻をずらしている間は、LIST も同じ時刻で計算する。

### TOUCH（指で見回す）

部屋の中で方位磁針が狂うとき、腕を上げにくいとき、空が見えないときに使う。
TOUCH にした瞬間に向いていた方位から始まる。

| 操作 | AR | MAP |
|---|---|---|
| ドラッグ | 左右で向き、上下で高さが変わる（空をつかんで動かす感じ） | 円にそって回す。中心近くでは左右で回る |
| 画面の左・右をタップ | 30度ずつ回る | 45度ずつ回る |
| 画面の上・下をタップ | 15度ずつ見上げる・見下ろす | － |

TOUCH の間は、右スワイプでアプリが閉じないようにしている。閉じるときは時計のボタンを使う。

### 星座線

56星座の線を引く（黄道12星座と、主な星座）。3.5等より明るい星は点で出る。
黄道12星座以外の星座名は薄い色で出す。

MAP180・MAP360 では、時計を動かしている間は線を省き、止まってから描く（重くならないように）。

### LIST

- Sun に「Dark sky」を足した。天文薄明が終わる時刻 - 始まる時刻（太陽が地平線の18度下より低い時間）。
  星を見るのに向いた暗い時間の目安。朝の時刻は、表示している日付の朝のもの。
- 明るい星に北極星（Polaris）を足した。

### そのほか

- 時計を動かさずに置いていても、30秒ごとに空を描き直す（時刻の進みに合わせる）。
- LIST から戻っても、表示モード・TOUCH・時間移動はそのまま（アプリを閉じると元に戻る）。
- `app.json` の権限に紛れていた `"device :os.compas s"` を消した。

## 時計に入れる（Termux）

前提：Termux に `zeus` が入っていて、`zeus preview` で時計に送れていること。

1. ブラウザで GitHub の `othermarrow/Claude` を開き、ブランチを選んで `Code` → `Download ZIP` で
   Download フォルダに保存する。
2. Termux で次を実行する。`B=` の右は、保存された zip の名前（`.zip` を除いたもの）に合わせる。

```bash
B=Claude-main
cd ~
unzip -o /storage/emulated/0/Download/$B.zip "$B/starmap/*"
rm -rf ~/starmap-new
mv $B/starmap ~/starmap-new
rm -rf $B
cd ~/starmap-new
zeus preview
```

表示された QR コードを Zepp アプリ（開発者モード）で読み取ると、時計に入る。
appId（27416）は元のアプリと同じなので、上書きで入る。
`zeus` が部品が足りないと言ったときは、`~/starmap-new` で `npm i` してからもう一度送る。

## 重さを調整する

`page/index.js` の上のほうの数字で変えられる。

| 名前 | 今の値 | 意味 |
|---|---|---|
| `LINES` | 1 | 0 にすると星座線を引かない |
| `LINES_FAST` | `[1,1,0,0]` | 動かしている間も星座線を引くか（AR, MAP90, MAP180, MAP360 の順） |
| `DOTMAG` | 3.5 | この等級より明るい星を点で描く。小さくすると点が減って軽くなる |
| `PERF` | 0 | 1 にすると1回の描画にかかった時間（ms）が出る |
| `NIGHT_H` | 21 | 時刻をタップしたときに飛ぶ時刻 |
| `ALT0` | 10 | TOUCH の AR を始めたときの高さ（度） |

## 確かめたこと・まだのこと

- パソコン上（Node.js）で Zepp OS の部品をまねた仕組みを作り、画面を絵にして確かめた。
  - SENSOR のときの方位・高さ、星・惑星・太陽・月の位置は、元のコードと同じになる（AR 4通り、MAP 3通り）。
  - TOUCH のドラッグ・タップ・スワイプ、時間移動のボタン、LIST の時刻と Dark sky。
- **実機ではまだ試していない。** とくに次の3つは時計で動かして確かめる必要がある。
  - TOUCH のドラッグとタップ：画面全体に透明な TEXT を置いてタッチを受けている。
    これが届かない場合は、スワイプ（左右で45度、上下で15度）だけで動く。
    TOUCH の間に右スワイプでアプリが閉じないことも確かめる。
  - -1h / +1h の長押し（`longpress_func`）。
  - MAP360 を止めたときの描画の重さ。描く線と点が元の約2.4倍（339回 → 804回）になる。
    重ければ `DOTMAG` を下げるか `LINES` を 0 にする。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `page/index.js` | 星図の画面（AR・MAP、時間移動、TOUCH） |
| `page/list.js` | 一覧の画面 |
| `page/diag.js` | センサー確認用の画面（`app.json` には登録していない） |
| `utils/astro.js` | 太陽・月・惑星の位置の計算 |
| `utils/outer.js` | 天王星・海王星の位置 |
| `utils/sky.js` | 時計の向きから、空の座標への変換 |
| `utils/glyph.js` | 惑星・星座の記号 |
| `utils/skydata.js` | 星と星座線のデータ（`tools/gen_skydata.py` で作る） |
| `utils/state.js` | ページのあいだで共有する状態 |
| `tools/gen_skydata.py` | `utils/skydata.js` を作り直す（ネットにつながった Termux で `python3 tools/gen_skydata.py`） |

星座線と星の等級は [d3-celestial](https://github.com/ofrohn/d3-celestial)（BSD-3-Clause、`tools/LICENSE-d3-celestial.txt`）のデータを使っている。
