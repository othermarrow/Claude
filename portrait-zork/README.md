# 五枚目の額(portrait-zork)

四つのAIが書いた「あなたの人物像」と、自分の物語の中身を素材にした、Zork + Backrooms 風のテキストアドベンチャー。
四枚の人物像を重ねて読んでいたら、紙の継ぎ目から黄色い部屋(Level 0)へすり抜けてしまったところから始まる。
肖像の間の四枚の額は、それぞれ一つのAIの人物像で、その向こうの階層では、そのAIが書いた「あなたのやり方」で一つ仕事を終える。
すると額の「隅」が一つ手に入る。四つの隅で五枚目の額(記録にないもの)ができると、その向こうに、どのAIも読んでいない物語の階が開く。

見た目と操作は `brain-zork/`・`mirror-zork/`・`story-zork/` と同じ黄色い部屋で、「命令を作る」と十字キーで遊べる。

## 素材

| 額 | 元の文章 | 階層でやること |
|---|---|---|
| 北・付箋の額 → Level 2 地下の端末室 | Perplexity の三つの回答(人物像・印象に残ったやりとり・クセ) | バックアップ → 直す → 壊れたら元に戻して小さく直す → パッチの形式を確かめて手で当てる → 構文確認 → 小さく試す(溢れたら Crossref を絞る) → 本番 |
| 東・設計図の額 → Level 3 増築の廊下 | ChatGPT の人物像 | 廊下は「これも足せば便利」の部屋で伸びつづける。作業票の「今回の目的」「成功の条件」「触らない部分」を札で埋めると止まる。目的は自由に選べるが、「全部そろえば成功」では終わらない |
| 西・下書きの額 → Level 4 訂正の書庫 | Claude のレポート(確かめてから信じ、手元で作り直す) | 「本人の言葉」の判が押された記憶のカードを、出どころを確かめてから、AIの解釈だったものだけ訂正する |
| 南・数式の額 → Level 5 計数室 | Gemini の報告(性格推定の方法論) | 語彙の計数機に、依頼の束・物語の一枚・白いカードを入れて比べる。白紙に「判断材料不足」と出たとき、初めて正確な答えになる |
| 五枚目の額 → Level 6 物語の階 | 自分の物語(251 作品)の場面 | 〈解釈の手〉が物語の場面に貼った心理学のラベルを剥がす。最後に、一枚を五枚目の額に掛けるか、何も掛けないかを決める |

- 人物像の文章はそのまま使わず、言い換えている(エラー文など、ごく短い決まった文言は残した)。
- 物語については、題名・ユーザー名・投稿サイトの名前は使わず、場面を言い換えて使っている。
- 物語の階は、「物語の語り手の言葉から書き手の性格を読む」ことをしない、という作りにしている。

## 階層としくみ

| 階層 | 場所 | すること |
|---|---|---|
| Level 0 | 黄色い部屋 | 壁や床に、人物像と物語の切れはしが混ざっている。脚注を読むと、一つ小さい番号の方角が分かる。たどって ⁂ の印を「すり抜ける」 |
| Level 1 | 肖像の間(安全地帯) | 入ると正気度が戻る。北・東・西・南へ進むと、それぞれの額の向こうへ。五枚目の額に隅をはめる |
| Level 2〜5 | 四つの額の向こう | 上の表のとおり |
| Level 6 | 物語の階 | ラベルを剥がす。ぼんやり待っていると、〈解釈の手〉がまた貼りにくる |
| 出口 | 五枚目の額 | 絵を一枚「掛ける」か「掛けない」 |

「正気度」は、黄色い部屋をさまよう、戻る地点を作らずに壊す、完全版でまるごと差し替える、確かめずに訂正する、本人の言葉を訂正しかける、
物語の数字を自分のものとして手に取る、などで減る。0 になっても死にはせず、肖像の間(まだなら黄色い部屋)で目を覚ます。
困ったら「わからない」と言うと、ヒントを一つ出す。

## 遊び方

- claude.ai のページ(本人だけが開ける。Chrome の「ホーム画面に追加」でアプリのように起動できる)
- Tasker のシーンで遊ぶときは `portrait-zork-standalone.html` を Webビューで開く。
  手順は `zork-ja/README.md` の「Tasker のシーンで遊ぶ」と同じで、置き場所だけ変える。

```bash
mkdir -p /storage/emulated/0/Tasker/portrait-zork
cp /storage/emulated/0/Download/portrait-zork-standalone.html /storage/emulated/0/Tasker/portrait-zork/portrait-zork.html
```

Webビューの「電話へのアクセスを許可」をオンにすると、途中の状態が
`Tasker/portrait-zork/portrait-zork-data.json` に残る(Tasker の変数 `%PORTRAITZORK` も使う)。

## ファイル

| ファイル | 役割 |
|---|---|
| `portrait-zork.html` | ゲーム本体(claude.ai に公開する形) |
| `build.py` | `portrait-zork-standalone.html`(Tasker やブラウザで直接開く形)を作る |
| `portrait-zork-standalone.html` | Tasker のシーン用 |

人物像の元の文章と、物語のアーカイブは、このリポジトリには入れていない。

## 確認できていること・いないこと

- 開発環境の Chromium(スマホの画面サイズ)で、黄色い部屋から四つの隅を集め、物語の階のラベルを剥がして脱出するまで通しで遊べた(掛ける・掛けないの両方の終わり方)。
  端末室の二つの道(元に戻して小さく直す/完全版を貼って直す)、作業票の「全部そろえば成功」の札、確かめずに訂正したとき、
  「命令を作る」・日本語の命令・英語の命令・続きから再開が動いた。
- Tasker の実機と claude.ai の中では、まだ確かめていない。
