# 種を煮る夜

眠れない夜の頭の中を、Backrooms 風の階層（Level）として歩くテキストアドベンチャー。
「五枚目の額」と同じ操作系（状態行・文章・「命令を作る」・十字キー・よく使う命令の6ボタン・≡ メニュー・自動保存）で、話と素材を新しくした。

- ファイル：`tane-wo-niru.html`（HTML 一枚。外から読みこむのは DotGothic16 フォントだけで、読めなくても遊べる）
- 素材：書いてきた物語（約250本）と文章、五つのAI（ChatGPT・Claude・Gemini・Manus・Perplexity）の分析
- 方針：文章はそのまま写さず、書き手の人となりを中心に組み直した。いくつかの一文だけ、そのまま置いている（下の一覧）
- 入れていないもの：投稿サイトの名前、そこで毎日出る題、ユーザー名・筆名、本名

## 遊び方

1. スマホのブラウザ、または Tasker のシーン（WebView）で `tane-wo-niru.html` を開く。
2. 「命令を作る」→ 動詞 → 物（「言う」なら、その場で言えることば）の順にタップする。入力欄に日本語で書いてもよい（例：`キーを押す`／`眼鏡をかける`／`「おはよう」と言う`）。
3. 各階で「種の紙」を見つけて「書く」と、ノートに頁が一枚増える。六枚で最上階が灯る。
4. 困ったら「わからない」。頭のどこかで、誰かが一つだけ答えてくれる。

## 階層

ボタンに四と九はない。四番目のボタンには「5」と書いてある。

| Level | 場所 | 書き手のどこを写したか |
|---|---|---|
| 0 | 黄色い部屋 | 何かしていないと嫌なモノが湧く頭。押されたことのないキーと、近道の配達員 |
| 1 | 欠番のエレベーター | ハブ。同僚から見た自分の鏡と、「開けるな」の点検口 |
| 2 | 大講義室 | 視線と自意識。人の目は頭の中にしかない／でも「すげー」とは言われたい |
| 3 | 冷凍倉庫・搬入口 | 夜勤の無感覚と、水たまりのアメンボ |
| 5 | 点検の部屋 | 確かめずにいられない性分と、「点検できたらOK」 |
| 6 | 夜の土間 | 眠れない夜の決まりごと。手を止めず、振り向かない |
| 7 | 生活棟の食堂前・池のほとり | 叫び声を、距離を置いて聞く。事実と主観を分ける |
| 8 | 細くなる廊下 | 心理的視野狭窄と外在化。「ある」を「いる」に |
| 10 | 問答の部屋 | 二人の自分。「わからない」と「分かるよ」 |

<summary>手順（ネタばれ）</summary>

- Level 0：歩くと三部屋ごとに Scroll Lock キーが落ちている → 押す → インターホンを押す → 近道の壁をすり抜ける
- Level 2：ひそひそ声を聞く（任意）→ 「見るな」と言う → 種の紙を取って書く
- Level 3：遺失物の棚の眼鏡を取ってかける → 待つ ×3（夜勤）→ 東 → 待つ（アメンボ）→ 「おはよう」と言う
- Level 5：気になる場所を一度ずつ確かめる（二度目は場所が増える）→ 「OK」と言う
- Level 6：豆の袋を鍋に入れる → かき混ぜる（勝手口が開いても振り向かない・喋らない・待たない）→ 眠気が来たら火を消す
- Level 7：東の池のほとりで耳をすます → 西へ戻ってケースファイルを読む → ふりかけをかける
- Level 8：針金のかたまりに名前をつける → 「何が」「いつから」と言う（「なぜ」は狭くなる）
- Level 10：座る →（何を言っても「違う」）→ 「わからない」→ エレベーターの点検口を開ける

</details>
