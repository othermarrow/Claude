# 降下記録

黄色い部屋（Level 0）から、下へ下へと順番に降りていくサイコホラーのテキストアドベンチャー。
Zork と Backrooms 派生ゲームに寄せて作った。最初は、自分が誰で、何のために降りるのかも分からない。

- ファイル：`tane-wo-niru.html`（HTML 一枚。外から読みこむのは DotGothic16 フォントだけで、読めなくても遊べる）
- 操作系：「五枚目の額」と同じ（状態行・「命令を作る」・十字キー・よく使う6ボタン・≡ メニュー・自動保存）。十字キーの左上に「上」、右下に「下」を足した
- 素材：アップロードされた物語・文章・各AIの分析。文章は引用せず、世界観と仕掛けに溶かした
- 文章：すべて標準語
- フォルダ名とファイル名は、Tasker のシーン設定がそのまま使えるように、前作「種を煮る夜」のときのまま残した

## 遊び方

1. スマホのブラウザ、または Tasker のシーン（WebView）で `tane-wo-niru.html` を開く。
2. 「命令を作る」→ 動詞 → 物 の順にタップする。入力欄に日本語で書いてもよい（例：`木箱を開ける`／`懐中電灯を点ける`／`鍵を鍵穴に入れる`）。
3. 困ったら「わからない」。

### Tasker で開く

1. Termux で置き場所を作ってコピーする。

   ```sh
   mkdir -p /storage/emulated/0/Tasker/tane-wo-niru
   cd ~/Claude
   git fetch origin ccr-d4f31da7-u5hlbp
   git checkout ccr-d4f31da7-u5hlbp
   cp tane-wo-niru/tane-wo-niru.html /storage/emulated/0/Tasker/tane-wo-niru/
   ```

2. Tasker でシーンを作り、WebView を全面に置く。Mode は `URI`、Source は `file:///storage/emulated/0/Tasker/tane-wo-niru/tane-wo-niru.html`。Allow Phone Access と Allow Universal Access をオンにする。
3. 「シーン表示」の Display As は Activity, Full Window にする（オーバーレイだとキーボードが出ない）。

## しくみ

| 項目 | 内容 |
|---|---|
| 正気 | 0〜10。暗闇、寒さ、決まりごとを破る、立ち止まる、見てはいけないものを読むと減る。アーモンド水で戻る。0 になるとその階の入口で目を覚ます（最下層だけは別） |
| 暗闇 | 灯りがないと何も見えず、動きつづけると「数える声」に触れられる |
| 記録の書き換え | ときどき、過去に打った命令が、打っていない命令に変わる |
| 頭の右上 | 正気が減ったときや、ある階を過ぎたあと、右上に何かが浮かぶ |
| トランシーバー | 持ち歩くと、ときどき自分の声で、自分が前にしたことを言う |
| 周回 | ある終わり方をすると、次の「はじめから」で少しだけ世界が変わる（前の周の自分の声が残る） |
| 保存 | localStorage（`tanewoniru.state`、周回は `tanewoniru.state.loop`）。Tasker のシーンでは `/storage/emulated/0/Tasker/tane-wo-niru/tane-wo-niru-data.json` にも書き、書いたあとで変数 `%TANEWONIRU` を 1 にする。前作の保存は読みこまない |

## 階層

| Level | 場所 | 素材にしたもの |
|---|---|---|
| 0 | 黄色い部屋 | 止まると嫌なものが増える頭 |
| 1 | 搬入通路・冷凍室 | 夜勤の倉庫、会話のない夜 |
| 2 | 配管 | 狭まる視野と、名前をつけて距離を取ること |
| 3 | 同じ部屋の廊下 | 確かめずにいられない癖、欠番の四 |
| 4 | 夜の生活棟 | 叫び声を離れて聞くこと、記録と「できる」 |
| 5 | 土間 | 眠れない夜の決まりごと |
| 6 | 最下層 | 背を向けて書きつづける自分 |

<summary>手順（ネタばれ）</summary>

- Level 0：「耳をすます」でうなりの強い方角が分かる。その方角へ進みつづけると、灯りの切れた部屋に着く → 下
- Level 1：事務所でバールとロッカーの懐中電灯・手袋を取る → 木箱をバールで開ける（アーモンド水）→ 手袋をはめて断熱扉を開ける → 霜のない箱を開けて鍵を取る（灯りが消える。懐中電灯を点ける）→ 貨物エレベーターの鍵穴に鍵を入れる → 下
- Level 2：ボイラー室でバルブを閉める、缶の手紙を読む → 細い通路の突き当たりまで北へ → 針金の塊に名前をつける → 下
- Level 3：どれかの扉から部屋に入る → 気になる場所を一度ずつ確かめる（二度目は場所が増える）→ 「もういい」と言う → 番号のない扉 → 下
- Level 4：食堂の白い紙と鉛筆 → 中庭で耳をすます → 書く → 詰所の電話を取る → 下
- Level 5：懐中電灯を消す → 豆の袋を鍋に入れる → かき混ぜる（振り向かない・声を出さない・待たない）→ 眠気が来たら火を消す → 下
- Level 6：人影には触れない → 空いた椅子に座る → 「わからない」

## 確認したこと

- Chromium（スマホ幅 412px）で、二つの終わり方まで通しで遊べること、二周目の変化、各階でのランダム操作（各150回）で例外が出ないことを確かめた。
- 実機（Xperia 1 IV のブラウザ、Tasker のシーン）では、まだ確かめていない。
