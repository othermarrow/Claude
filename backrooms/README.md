# 迷い部屋（backrooms）

Backrooms 風の探索ホラー。終わりのない黄色い部屋をさまよい、出口を探して下の層へ進む。
ゲームは HTML 1枚（`backrooms.html`、約80KB）だけでできていて、ネットにはつながない。
Tasker のシーンに WebView を1つ置いて遊ぶ（Chrome でも動く）。

- 一人称でなめらかに歩く3D（昔の3Dシューティングと同じ「レイキャスト」という描き方）
- 壁紙・カーペット・天井・蛍光灯はすべてプログラムで描いたもの。画像ファイルは使っていない
- 蛍光灯のうなり、足音、出口の音、怪物の足音などは、ブラウザの中で合成している。音のファイルも使っていない
- 部屋は歩くたびにその場で作られ、終わりがない。はじめからやり直すたびに形が変わる

「Backrooms」はネットのみんなで作られてきた設定。このゲームは「黄色い部屋が延々と続く」という考え方だけを借りて、
層・怪物・メモの文章はこのゲームのために作った。

## 層

| 層 | 名前 | ようす | 出口 | 出口の音 |
|---|---|---|---|---|
| 第0層 | 黄色い部屋 | 黄ばんだ壁紙、湿ったカーペット、蛍光灯 | 非常口 | オルゴール |
| 第1層 | 灰色の倉庫 | コンクリートの柱と棚。暗い区画が多い | 階段室の扉 | ラジオ |
| 第2層 | 配管の通路 | 狭く曲がりくねった通路。赤い灯り | 点検口 | 風 |
| 第3層 | 消灯した事務所 | ほとんど真っ暗。懐中電灯が頼り | エレベーター | チンという音 |
| 第4層 | 白いタイルの部屋 | 明るく静か。正気が戻る | 光の漏れる扉 | 和音 |

第4層の扉を抜けるとエンディング。

## 遊び方

### 操作（スマホ）

| 操作 | すること |
|---|---|
| 画面の左半分をなぞる | 歩く（なぞった向きへ。横にも歩ける） |
| 画面の右半分を左右になぞる | 向きを変える |
| 走 | 走る・歩くの切り替え。速いが足音が大きく、体力が減る |
| 灯 | 懐中電灯。電池が減る。予備の電池は自動で入れ替わる |
| 水 | 水を飲む。渇きと正気が戻る |
| 図 | 地図の切れ端を使う。30秒のあいだ、出口の向きと距離が出る |
| Ⅱ | 一時停止（拾ったメモを読み返せる） |

出口の前に立つと「非常口の扉を開ける」などのボタンが出る。

キーボードでも遊べる：WASD・矢印で移動、Shift で走る、F でライト、Q で水、M で地図、E で出口、Esc で一時停止。

### 決まりごと

- **正気**：時間とともに少しずつ減る。暗い所にいる（ライトなし）、怪物を見る、喉が渇ききっていると早く減る。0 になると終わり。水を飲むと少し戻る。
- **水分**：時間とともに減る。0 になると歩くのが遅くなり、正気も減りやすくなる。
- **電池**：ライトをつけている間だけ減る。1本で約4分。
- **体力**：走ると減り、歩くか止まると戻る。切れると、しばらく走れない。
- 床に落ちている水・電池・地図の切れ端・メモは、上を歩くと拾う。

### 出口の探し方

各層の出口は、スタートから歩いて50歩くらいの所にある（壁の配置で遠回りになることもある）。
出口からは音が出ていて、近づくほど大きく、壁の向こうだとこもって聞こえる。
**イヤホンをすると、左右どちらから聞こえるかで方向が分かる。**

### 怪物

- **徘徊者**（第1層から。第0層にもまれに）：顔のない、細長い黒い影。足音を聞いて寄ってくる。
  見つかると追ってくるが、走れば引き離せる。見えない所に逃げてしばらくすると、見失う。走る足音は遠くまで届く。
- **笑う闇**（第3層）：暗がりにしかいられない。暗い所にいると、笑い声とともに近づいてくる。
  ライトを当て続けると、嫌がって逃げ、やがて消える。明るい所までは入ってこない。
- 心臓の音が聞こえたら、近くで何かが追ってきている。

捕まるか正気を失っても、その層の最初からやり直せる（持ち物はその層に入ったときに戻る）。

## スマホに入れる

zip で受け取った場合は、Download フォルダに保存してから、Termux で展開する。

```bash
cd /storage/emulated/0/Download
unzip -o backrooms.zip
cp backrooms/backrooms.html /storage/emulated/0/Download/backrooms.html
```

（`unzip` がなければ `pkg install -y unzip`。初めて Termux から Download を使うときは `termux-setup-storage`）

## Tasker で開く

（実機ではまだ試していない。Tasker の画面の言葉は、版や日本語訳によって少し違うことがある）

1. 「シーン」タブで「＋」を押し、名前を `迷い部屋` にする。シーンの枠を画面いっぱいまで広げる。
2. 要素を追加して「WebView」を選ぶ。
   - モード：URI
   - ソース：`file:///storage/emulated/0/Download/backrooms.html`
   - JavaScript やファイルへのアクセスを許可する項目があれば、オンにする
   - 要素の大きさもシーンいっぱいに広げる
3. 「タスク」タブで新しいタスク `迷い部屋を開く` を作り、アクション「シーン」→「シーンを表示」を足す。
   - 名前：`迷い部屋`
   - 表示方法：「アクティビティ」の全画面のもの（Activity, Full Window など）
4. ホーム画面にこのタスクのショートカットを置く。

表示されないときは、まずファイルマネージャーで `backrooms.html` を Chrome で開いてみる。Chrome で動けば、Tasker の WebView の設定の問題。
音が出ないときは、WebView が音を止めている可能性がある（ゲームは「はじめから」を押したときに音を鳴らし始める）。

## 記録

- 4秒ごとと、物を拾ったときなどに、自動で保存する（WebView の保存領域 `localStorage`）。
- 層の途中で閉じても、次は同じ場所から続く。怪物は消えている。
- エンディングを見ると記録は消え、タイトルに「脱出した回数」が残る。
- タイトルに「記録が保存されないようだ」と出たときは、その WebView では保存が残らない。

## 設定

- **画質**（低い・普通・高い）：動きがかくかくするときは下げる。重いと感じると自動で1段下げる。
- **向きを変える速さ**、**音量**、**振動**

## 作り直し・テスト

ゲームの元は `src/` にあり、`build.js` で1枚の `backrooms.html` にまとめる。遊ぶだけならビルドはいらない。

```bash
cd backrooms
node build.js               # src/ → backrooms.html
node test/world_test.js     # 5つの層を30通りずつ作って、出口に歩いて行けるか
```

`test/ui_test.js`・`ai_test.js`・`run_test.js` は Playwright でブラウザを動かすテスト（Claude の作業環境で実行した）。
スマホの画面の大きさ（411×890）で、全部の画面、怪物の動き、正気・渇き・電池の減り方を確かめた。
自動操縦で第0層からエンディングまで、道を知っている場合は種6通りすべて、寄り道しながらの場合は種3通りすべてで通った。
描画は1フレーム約3.5ms（作業環境のパソコンで。スマホではもっとかかる）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `backrooms.html` | 遊ぶためのファイル（`build.js` が作る） |

| `src/game.js` | 移動、正気・渇き・電池、拾う物、怪物の動き、保存 |
