# 迷い部屋（backrooms）

Backrooms 風の探索ホラー。終わりのない黄色い部屋をさまよい、出口を探して下の層へ進む。
ゲームは HTML 1枚（`backrooms.html`、約180KB）だけでできていて、ネットにはつながない。
Tasker のシーンに WebView を1つ置いて遊ぶ（Chrome でも動く）。
Chrome で「アプリとして入れる」版（`pwa/`）もある。ホーム画面のアイコンから全画面で開き、Termux を止めていても遊べる（[アプリとして入れる](#アプリとして入れるchrome)）。

- 一人称でなめらかに歩く3D（昔の3Dシューティングと同じ「レイキャスト」という描き方）
- 壁紙・カーペット・天井・蛍光灯はすべてプログラムで描いたもの。画像ファイルは使っていない
- 蛍光灯のうなり、足音、出口の音、怪物の足音などは、ブラウザの中で合成している。音のファイルも使っていない
- 部屋は歩くたびにその場で作られ、終わりがない。はじめからやり直すたびに形が変わる

「Backrooms」はネットのみんなで作られてきた設定。このゲームは「黄色い部屋が延々と続く」という考え方だけを借りて、
層・怪物・メモの文章はこのゲームのために作った。

## 6つの遊び方

タイトル画面で選ぶ（救いのない版から下は「ほかの版」の中）。記録（つづき）は1つだけで、別の遊び方を始めると消える。

| 遊び方 | 内容 |
|---|---|
| はじめから | 出口を探して10の層を抜けると、エンディング。捕まってもその層の最初からやり直せる |
| 救いのない版 | 層が終わらない。最後の光の扉の先も、また黄色い部屋（第10層、第11層…と続く） |
| 原作版 | 2019年の最初の投稿に合わせた版。黄色い部屋だけで、出口はない |
| Wiki設定版 | その後ネットの The Backrooms Wiki で広がった設定（Level・Entity・アーモンドウォーター）で、14の Level を歩く |
| 五つの報告書 | 5つのAI（Perplexity・Manus・Gemini・Claude・ChatGPT）が書いた「あなたについての報告書」の中を、10の層で歩く |
| 山羊文学版 | 山羊文学の作品の言葉が、メモになって床に落ちている。10の層 |

### 救いのない版

- 10の層をくり返すたびに、暗くなり、灯りが減り、怪物が増えて少し速くなり、出口が遠くなり、出口の音が届く距離も短くなる。画面からは色が抜けていく。
- 拾える水と電池は半分ほど、地図の切れ端は出ない。電池の減りは3割速い。
- 水を飲んでも、渇きがおさまるだけで正気は戻らない。白いタイルの部屋でも正気は戻らない。
- 捕まるか正気を失ったら、そこで終わり。やり直しはない（記録は消える）。
- 死んだときのことは「メモ」になって残る。次の救いのない版で、そのメモを拾うことがある。
- メモは12枚の別の文章。タイトルには、いちばん深く進んだ層が残る。

### 原作版

- 2019年に掲示板へ投稿された最初の Backrooms（写真1枚と短い文章）に合わせた。
  湿ったカーペットの匂い、黄色一色、うなり続ける蛍光灯、区切られただけの空っぽの部屋。
  近くで何かが歩き回る音がしたら、それはもう、こちらの音を聞いている。
- 出口・層・持ち物・メモ・懐中電灯・正気や渇きの表示はない。できるのは歩くことと走ることだけ。
- 1分ほどすると「何か」がひとつ現れる。それはときどき、こちらの居場所を聞きつけてやって来る。
  時間がたつほど、聞きつける間隔は短く、場所は正確になり、足も速くなる。遠くへ逃げても、いつのまにか近くにいる。
- 時間がたつほど、画面は黄色一色に近づき、ざらついていく。
- 捕まったら終わり。生き延びた時間が記録される。
- 投稿の写真や文章そのものは使っていない（画面の文章はこのゲームのために書いた）。
- 自動操縦で試したところ、立ち止まっていると約1分半、近づかれたら離れるように動くと2〜4分で捕まった。

### Wiki設定版

2019年の投稿のあと、The Backrooms Wiki（[backrooms-wiki.wikidot.com](https://backrooms-wiki.wikidot.com/)）でみんなが書き足して広がった設定をもとにした版。
利用者が Termux で保存した Wiki のページ（Level 0〜11・26・37、Entity 3・4・8・9・10・67・110 と一覧、Object 1「Almond Water」、M.E.G.）を読んで、Level の名前・様子・出てくるもの・Level どうしのつながり・Entity の動きを合わせた。
画面の文章（メモ・札・捕まったときの文・エンディング）は、Wiki の説明をもとに、このゲームのために短く書いた。
いくつかの文は Wiki の一文の訳に近い（Level 0 の札の「入り口であり、墓場でもある」、Level 6 の「何もいないから危ない」、Level 10 の「一瞬、Backrooms から出られたのかと思った」、Level 37 の「落ち着いた気持ちになる」など）。

- 水のかわりに**アーモンドウォーター**を拾う。飲むと渇きと正気が戻る（正気は「はじめから」の水より多く戻る）。Wiki では、ほのかに甘くアーモンドの香りがして、1本で食事1回ぶんになる。
- Entity の動き（Wiki の Entity のページから）：
  - **ハウンド**：人を見つけると襲ってくる。にらみ返すと、少しのあいだだけひるむ（このゲームでは2秒ほど止まる）。
  - **スマイラー**：光を持っているものを追う。目を合わせたまま、ゆっくり下がるのが一番。走ったり大きな音を立てたりすると襲ってくる。
  - **デスモス**：明るい光に寄ってくる。
  - **フェイスリング**：ほとんどはおとなしい（このゲームでは何もしてこない）。
  - **パーティーゴーアー**：近くしか見えず、足も遅いが、とても静か。群れで動く。
  - **肉食の風船**：自分では動かない。近づいたものをリボンでつかまえる。光や音には寄ってこない。
- メモは「M.E.G.（Major Explorer Group）の記録」。札には Level の英語名と生存難易度が出る。
- 捕まっても、その Level の最初からやり直せる。拾う物の絵は設定で切りかえられる（ふつうの絵にするとアーモンドウォーターの瓶になる）。

**このゲームでの解釈（Wiki のとおりではないところ）**
- Level 0〜11 は、Wiki に書かれたつながりのとおりにつないだ（Level 7 → 8 は Level 7 のページの「水中の洞窟」。Level 8 のページは Level 6 からの道として書いている）。
- Level 11 → Level 26：Wiki では「どこにいても、パーティーの飾りにさわると Level 26 へ引きこまれる」とある。このゲームでは、Level 11 の壁に貼られたパーティーのポスターから行く。
- Level 7 は本当は泳いで深く潜る海だが、このゲームでは水の上を歩く（遅くなる）。息や深さはない。タイニーと「7層のもの」の姿はページにくわしく書かれていないので、影として描いた。
- Level 9〜11 は外だが、このゲームでは建物や生け垣を同じ高さの壁で描き、天井のかわりに空を描いた。
- Level 26 → Level 37：Wiki では、ポスターから行く先は「別の Level」としか書かれていない（Level 4 に出た人の話がある）。このゲームでは Level 37 へ出る。
- Level 37 の先：Wiki では、水に潜ると別の Level（Level 130 など）へ出る。このゲームではエンディングにした。
- Level 6 は、まったく見えないと遊べないので、ほんの少しだけ形が見える。出口からはパーティーの音楽がかすかに聞こえる。
- Entity の動き（速さ、何に寄ってくるか）は、Wiki の説明をもとにした、このゲームでの作り。
- 以前この版に入れていた Level !（Run For Your Life）は、今の Wiki の Level の一覧になかったので外した。Level Fun は、今の Wiki では Level 26「The SS Fun =)」になっていた。
- アーモンドウォーターで正気が戻るのは、このゲームのしくみ（Wiki には正気という数値はない。青いアーモンドウォーターが不安をやわらげる、とある）。

### 五つの報告書

- 5つのAIに「過去のやりとりから、わたしの性格をまとめて」と頼んで返ってきた報告書が元になっている。
  1つの報告書につき2つの層。メモには、その報告書の文を短く言いかえたもの、またはそのままの文が書いてある（メモの下に、どのAIの報告書かが出る）。
- 名前・住んでいる所・職場・仕事の相手・健康など、個人がわかる言葉は入れていない。性格やクセ、考え方についての文だけを使った。
- 歩き方・正気・渇き・電池・捕まったときのやり直しは「はじめから」と同じ。

### 五つの報告書・山羊文学版の共通点

- 拾う物（水・電池・地図の切れ端・メモ）は、絵を描き分けず、すべてオレンジ色の Claude 風のマークで表した。拾えば中身はちゃんと効く（この2つの版では、設定を変えてもマークのまま）。
- 部屋の形・灯り・出口の音は、ふつうの10の層と同じものを使っている（名前と壁と文章だけが変わる）。

| 第5層 | 地下駐車場 | 白線と柱だけが続く広い空間。隠れる場所が少ない | 出口のスロープ | 車の警報 |
| 第6層 | 書庫の迷路 | 本棚の迷路。暗がりに笑う闇 | 閲覧室の扉 | 時計の音とチャイム |
| 第7層 | 閉店したゲームセンター | 電源の落ちた筐体の列。ネオンのカーペット | 半分開いたシャッター | 電子音のメロディー |
| 第8層 | 病院の廊下 | 廊下と病室が続く。いちばん危ない（徘徊者と笑う闇の両方） | 両開きの扉 | 心電図の音 |
| 第9層 | 白いタイルの部屋 | 明るく静か。正気が戻る | 光の漏れる扉 | 和音 |

## 遊び方

### 操作（スマホ）

| 操作 | すること |
|---|---|
| 画面の左半分をなぞる | 歩く（なぞった向きへ。横にも歩ける） |
| 画面の右半分を左右になぞる | 向きを変える |
| 走 | 走る・歩くの切り替え。速いが足音が大きく、体力が減る |
| 灯 | 懐中電灯。電池が減る。予備の電池は自動で入れ替わる |
| 水 | 水を飲む。渇きと正気が戻る |
| 図 | 地図の切れ端を使う。30秒のあいだ、出口の向きと距離が出る |
| Ⅱ | 一時停止（拾ったメモを読み返せる） |

出口の前に立つと「非常口の扉を開ける」などのボタンが出る。

キーボードでも遊べる：WASD・矢印で移動、Shift で走る、F でライト、Q で水、M で地図、E で出口、Esc で一時停止。

### 決まりごと

- **正気**：時間とともに少しずつ減る。暗い所にいる（ライトなし）、怪物を見る、喉が渇ききっていると早く減る。0 になると終わり。水を飲むと少し戻る。
- **水分**：時間とともに減る。0 になると歩くのが遅くなり、正気も減りやすくなる。
- **電池**：ライトをつけている間だけ減る。1本で約4分。
- **体力**：走ると減り、歩くか止まると戻る。切れると、しばらく走れない。
- 床に落ちている水・電池・地図の切れ端・メモは、上を歩くと拾う。
- 物を拾う音は小さめ。蛍光灯のうなりと、ちらつく灯りのジッという音は大きめ（近くの3マスまでのちらつきが聞こえる）。
- 自分の足音は小さめに鳴る（走ると少し大きくなる）。怪物が足音を聞きつける距離は、音の大きさとは別に決まっている（歩くと4マス、走ると13マス）。

### 出口の探し方

各層の出口は、スタートから歩いて50歩くらいの所にある（壁の配置で遠回りになることもある）。
出口からは音が出ていて、近づくほど大きく、壁の向こうだとこもって聞こえる。
**イヤホンをすると、左右どちらから聞こえるかで方向が分かる。**

### 怪物

- **徘徊者**（第1層から。第0層にもまれに）：顔のない、細長い黒い影。足音を聞いて寄ってくる。
  見つかると追ってくるが、走れば引き離せる。見えない所に逃げてしばらくすると、見失う。走る足音は遠くまで届く。
- **笑う闇**（第3層・第6〜8層）：暗がりにしかいられない。暗い所にいると、笑い声とともに近づいてくる。
  ライトを当て続けると、嫌がって逃げ、やがて消える。明るい所までは入ってこない。
- 心臓の音が聞こえたら、近くで何かが追ってきている。

捕まるか正気を失っても、その層の最初からやり直せる（持ち物はその層に入ったときに戻る）。

## スマホに入れる

zip で受け取った場合は、Download フォルダ（`/storage/emulated/0/Download`）に保存してから、Termux で次を実行する。
Download の中で、ゲームの入ったいちばん新しい `backrooms〜.zip`（`backrooms (1).zip` のように名前が変わっていてもよい）を展開して、
Tasker 用のフォルダ `/storage/emulated/0/Tasker/backrooms/` に `backrooms.html` を置く。
アプリとして入れる版（`pwa/`）は、Termux のホームの `~/backrooms_pwa/` に置く。

```bash
cat > ~/update_backrooms.sh <<'EOF'
#!/data/data/com.termux/files/usr/bin/bash
set -e
DL=/storage/emulated/0/Download
DST=/storage/emulated/0/Tasker/backrooms
PWA=$HOME/backrooms_pwa
command -v unzip >/dev/null || pkg install -y unzip
# 新しい順に見て、中に backrooms/backrooms.html が入っている zip だけを使う
# （Wiki のページを保存した backrooms_wiki.zip などは選ばない）
ZIP=""
while IFS= read -r z; do
  if unzip -l "$z" 2>/dev/null | grep -q "backrooms/backrooms.html"; then ZIP="$z"; break; fi
done < <(ls -t "$DL"/backrooms*.zip 2>/dev/null)
if [ -z "$ZIP" ]; then
  echo "$DL に、ゲームの入った backrooms の zip が見つかりません"
  exit 1
fi
echo "使う zip: $ZIP"
TMP=$HOME/.backrooms_unzip
rm -rf "$TMP"
mkdir -p "$TMP" "$DST"
unzip -o -q "$ZIP" -d "$TMP"
cp "$TMP/backrooms/backrooms.html" "$DST/backrooms.html"
echo "更新しました: $DST/backrooms.html"
if [ -d "$TMP/backrooms/pwa" ]; then
  rm -rf "$PWA"
  cp -r "$TMP/backrooms/pwa" "$PWA"
  echo "アプリとして入れる版も更新しました: $PWA"
fi
rm -rf "$TMP"
EOF
bash ~/update_backrooms.sh
```

2回目からは `bash ~/update_backrooms.sh` だけでよい。
（初めて Termux からストレージを使うときは、先に `termux-setup-storage` を実行して許可を出す）

## Tasker で開く

（Xperia 1 IV の Tasker で、縦向きの表示までは動いた。Tasker の画面の言葉は、版や日本語訳によって少し違うことがある）

1. 「シーン」タブで「＋」を押し、名前を `迷い部屋` にする。シーンの枠を画面いっぱいまで広げる。
2. 要素を追加して「WebView」を選ぶ。
   - モード：URI
   - ソース：`file:///storage/emulated/0/Tasker/backrooms/backrooms.html`
   - **Allow Phone Access**（端末へのアクセスを許可する項目）をオンにする。
     オフのままだと、この WebView では記録が保存されず、タイトルに「記録が保存されないようだ」と出る。
     オンにすると、ゲームは Tasker の関数 `global`・`setGlobal` を使って、記録を Tasker のグローバル変数 `%BrSave`（つづき）と `%BrOpts`（設定）に保存する。
   - 要素の大きさもシーンいっぱいに広げる
3. 「タスク」タブで新しいタスク `迷い部屋を開く` を作り、アクション「シーン」→「シーンを表示」を足す。
   - 名前：`迷い部屋`
   - 表示方法：「アクティビティ」の全画面のもの（Activity, Full Window など）
4. ホーム画面にこのタスクのショートカットを置く。

### 横向きで遊ぶ

ゲームは縦向きでも横向きでも遊べる。

Tasker のシーンは、縦向きと横向きで、大きさと位置を別々に覚えている。
横向きの大きさを決めていないと、縦向きの配置を縮めて、画面のまん中に小さく出す（実機でそうなった）。
1. スマホの「自動回転」をオンにする。
2. 「シーン」タブで `迷い部屋` を開き、スマホを横にする（編集画面も横向きになる）。
3. 横向きのまま、シーンの枠と WebView を画面いっぱいまで広げて、保存する。

シーンを出したままスマホを回すと、Tasker が落ちることがあった。遊ぶ向きを決めてから開き、遊んでいる途中は回さないほうがよい。
（横向きの配置を直したあとの動きは、まだ試していない）

表示されないときは、まずファイルマネージャーで `backrooms.html` を Chrome で開いてみる。Chrome で動けば、Tasker の WebView の設定の問題。
音が出ないときは、WebView が音を止めている可能性がある（ゲームは「はじめから」を押したときに音を鳴らし始める）。

## アプリとして入れる（Chrome）

`pwa/` は、Chrome でホーム画面にアプリとして入れられる版。中身のゲームは `backrooms.html` と同じ。
Chrome の決まりで、アプリとして入れるには、ファイルを直接開くのではなく、サーバーから開く必要がある。
そこで、Termux の中だけで動くサーバー（このスマホの外からはつながらない）を、入れるときと更新するときだけ動かす。

1. 上の `update_backrooms.sh` を実行する（`~/backrooms_pwa/` に置かれる）。
2. Termux で次を実行する。Chrome で `http://127.0.0.1:8765/` が開く。

```bash
cat > ~/backrooms_app.sh <<'EOF'
#!/data/data/com.termux/files/usr/bin/bash
# 迷い部屋を Chrome でアプリとして入れる・新しい版に入れかえるときだけ使う、このスマホの中だけのサーバー
set -e
DIR=$HOME/backrooms_pwa
URL=http://127.0.0.1:8765/
command -v python >/dev/null || pkg install -y python
if [ ! -f "$DIR/index.html" ]; then
  echo "$DIR がありません。先に bash ~/update_backrooms.sh を実行してください"
  exit 1
fi
echo "Chrome で $URL を開きます（開かないときは、Chrome のアドレス欄にこの URL を入れる）"
echo "終わったら Termux に戻り、画面下の CTRL を押してから c を押して止める"
(sleep 1; termux-open-url "$URL") &
python -m http.server 8765 --bind 127.0.0.1 --directory "$DIR"
EOF
bash ~/backrooms_app.sh
```

3. タイトルに「アプリとして入れる」が出ていれば押す。出ていなければ、Chrome のメニュー（右上の︙）から「アプリをインストール」か「ホーム画面に追加」を選ぶ。
4. ホーム画面に「迷い部屋」のアイコン（黄色い廊下の奥に暗い戸口）ができる。Termux に戻ってサーバーを止める。
5. これからは、アイコンから開く。1度開いた中身はスマホに覚えているので、Termux を動かしていなくても遊べる。

新しい zip を受け取ったら、`bash ~/update_backrooms.sh` のあと `bash ~/backrooms_app.sh` を実行し、
サーバーが動いている間にアイコン（または Chrome）からゲームを1度開くと、新しい版に入れかわる。止めたあとも新しい版のまま。

アプリとして開いたときだけの動き：
- 画面全体を使って開く（上の時計や下のボタンの帯を出さない）。
- 遊んでいる間は、画面が暗くならない。一時停止やタイトルでは、ふつうどおり暗くなる。
- 遊んでいる途中に「戻る」（ボタンや、画面のふちからのスワイプ）をすると、アプリを閉じずに一時停止にする。

記録は Chrome の中（`http://127.0.0.1:8765` の保存領域）に残る。Tasker の版とは別々で、引きつがない。
番号 `8765` を変えると別のアプリあつかいになり、記録も別になるので、変えないこと。
Chrome の設定で、このサイトのデータを消すと記録も消える。

## 記録

- 4秒ごとと、物を拾ったときなどに、自動で保存する（WebView の保存領域 `localStorage`）。
  `localStorage` が使えない WebView では、Tasker のグローバル変数 `%BrSave`・`%BrOpts` に10秒ごとに保存する（上の「Allow Phone Access」が必要）。
- 層の途中で閉じても、次は同じ場所から続く。怪物は消えている。
- エンディングを見ると記録は消え、タイトルに「脱出した回数」が残る。
- タイトルに「記録が保存されないようだ」と出たときは、その WebView では保存が残らない。

## 設定

- **画質**（低い・普通・高い）：動きがかくかくするときは下げる。重いと感じると自動で1段下げる。
- **向きを変える速さ**、**音量**、**振動**
- 横向きにすると：横の見える範囲が広くなり（縦向き76°→横向き100°）、壁が画面を埋めつくさないように高さの見え方を変える。
  設定・一時停止・タイトルなどのボタンは2列に並べて、画面に収める。遊び方とメモは2段組みにする（長いときは指で上下になぞって読む）。
- **見た目**（ふつう・線だけ）：「線だけ」にすると、初期のウィザードリィのように、黒い画面に壁のふちだけを線で描く。
  遊び方・部屋の形・怪物・音は同じで、すべての版で使える。
  - 線の色は層ごとの壁と灯りの色（黄色い部屋は黄土色、配管の通路は赤など）。灯りの暗い所や遠くの線は見えにくくなり、懐中電灯で照らすと明るくなる。
  - 天井の灯りは四角いふちだけ。ちらつきや消えた灯りもそのまま。
  - 出口は、壁に描いた扉の形で、出口の光の色に光る。
  - 怪物や拾う物は輪郭だけ。目など自分で光るところと、Claude のマークはそのまま。
- **拾う物の絵**（Claude のマーク・ふつうの絵）：はじめは Claude のマーク。「はじめから」と救いのない版で、水・電池・地図・メモを全部オレンジ色の Claude 風のマークで描く。拾えば何だったかが出る。原作版には拾う物がない。

## 作り直し・テスト

ゲームの元は `src/` にあり、`build.js` で1枚の `backrooms.html` にまとめる。あわせて、アプリとして入れる版を `pwa/` に作る。遊ぶだけならビルドはいらない。

```bash
cd backrooms
node build.js               # src/ → backrooms.html と pwa/
node test/world_test.js     # 10の層を30通りずつ、救いのない版は第20層まで作って、出口に歩いて行けるか
```

`test/ui_test.js`・`ai_test.js`・`run_test.js`・`mode_test.js`・`wire_test.js`・`land_test.js`・`store_test.js`・`pwa_test.js` は Playwright でブラウザを動かすテスト（Claude の作業環境で実行した）。
スマホの画面の大きさ（411×890）で、全部の画面、怪物の動き、正気・渇き・電池の減り方を確かめた。
Wiki設定版・五つの報告書・山羊文学版は、始まり・拾う物の絵・メモと出典・怪物の絵・捕まったときの文・すべての層を抜けたエンディングの文を確かめた。
