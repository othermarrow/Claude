# ノークリップ

本家 Backrooms の設定で一から作ったテキストアドベンチャー。
現実から「すり抜けて」黄色い部屋（Level 0）に落ち、下のレベルへ進んでいく。最初は、何をすればいいのか分からない。

- ファイル：`noclip.html`（HTML 一枚。外から読みこむのは DotGothic16 フォントだけで、読めなくても遊べる）
- 操作：「降下記録」「空欄」と同じ（状態行・「命令を作る」・十字キー・よく使う6ボタン・≡ メニュー・自動保存）
- 文章：すべて標準語の書き下ろし
- 下敷き：The Backrooms（2019年の画像投稿から始まった共同創作）と、Backrooms Wiki などで共有されている設定。具体的には、レベルの名前と様子、実体（スマイラー、ハウンド、スキンスティーラー、フェイスリング、パーティーゴアー、ウレッチ）、M.E.G.、アーモンド水、ノークリップ、生存難易度クラス。設定だけを借り、文章は引用していない。謎解きや細かい決まりごとは、このゲーム独自のもの

## 遊び方

1. スマホのブラウザ、または Tasker のシーン（WebView）で `noclip.html` を開く。
2. 「命令を作る」→ 動詞 → 物（「言う」ならことば）の順にタップする。入力欄に日本語で書いてもよい（例：`懐中電灯を点ける`／`北の管に触る`／`鍵を鍵穴に入れる`）。
3. 困ったら「わからない」。

### Tasker で開く

1. Termux で置き場所を作ってコピーする。

   ```sh
   mkdir -p /storage/emulated/0/Tasker/noclip
   cd ~/Claude
   git fetch origin ccr-d4f31da7-u5hlbp
   git checkout ccr-d4f31da7-u5hlbp
   cp noclip/noclip.html /storage/emulated/0/Tasker/noclip/
   ```

2. 「降下記録」と同じようにシーンを作り、WebView の Source を `file:///storage/emulated/0/Tasker/noclip/noclip.html` にする（Mode は `URI`。Allow Phone Access と Allow Universal Access はオン。シーン表示は Activity, Full Window）。

### Tasker を使わずに開く

Download フォルダに `noclip.html` を置いて、Termux で次を実行してから、Chrome で `http://localhost:8000/noclip.html` を開く（遊んでいるあいだは Termux を閉じない）。

```sh
cd /storage/emulated/0/Download
python3 -m http.server 8000
```

## 保存

- localStorage の `noclip.state`。周回の記録は `noclip.state.loop`（はじめからやり直しても残る）。
- Tasker のシーンでは `/storage/emulated/0/Tasker/noclip/noclip-data.json` にも書き、書いたあとで変数 `%NOCLIP` を 1 にする。

## 確認したこと

- Node.js でゲーム本体だけを動かし、本道・風船の扉の道・スイッチを全部上げる道の三通りで帰還まで遊べること、四つの結末と、実体に襲われる場面の動きを確かめた。ランダムな命令 80,000 回で例外は出なかった。
- Chromium（スマホ幅 412px）で、ボタン操作・入力欄・レベルごとの色・はみ出しがないことを確かめた。
- 実機（Xperia 1 IV のブラウザ、Tasker のシーン）では、まだ確かめていない。
