# 空欄

白い部屋で目を覚ますテキストアドベンチャー。目的は、ゲームの中には書いていない。

- ファイル：`kuuran.html`（HTML 一枚。外から読みこむのは DotGothic16 フォントだけで、読めなくても遊べる）
- 操作：「降下記録」と同じ（状態行・「命令を作る」・十字キー・よく使う6ボタン・≡ メニュー・自動保存）。よく使うボタンの「すり抜ける」は「寝る」に替えた
- 素材：アップロードされた物語・文章を全部読み、混ぜて作った。文章は引用せず、場所・物・出来事に溶かした
- 文章：すべて標準語

## 遊び方

1. スマホのブラウザ、または Tasker のシーン（WebView）で `kuuran.html` を開く。
2. 「命令を作る」→ 動詞 → 物（「言う」「書く」はことば）の順にタップする。入力欄に日本語で書いてもよい。
3. 困ったら「わからない」。

### Tasker で開く

1. Termux で置き場所を作ってコピーする。

   ```sh
   mkdir -p /storage/emulated/0/Tasker/kuuran
   cd ~/Claude
   git fetch origin ccr-d4f31da7-u5hlbp
   git checkout ccr-d4f31da7-u5hlbp
   cp kuuran/kuuran.html /storage/emulated/0/Tasker/kuuran/
   ```

2. 「降下記録」と同じようにシーンを作り、WebView の Source を `file:///storage/emulated/0/Tasker/kuuran/kuuran.html` にする（Mode は `URI`、Allow Phone Access と Allow Universal Access はオン、シーン表示は Activity, Full Window）。

## 保存

- localStorage の `kuuran.state`。周回の記録は `kuuran.state.loop`（はじめからやり直しても残る）。
- Tasker のシーンでは `/storage/emulated/0/Tasker/kuuran/kuuran-data.json` にも書き、書いたあとで変数 `%KUURAN` を 1 にする。
