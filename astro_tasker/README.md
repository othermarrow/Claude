# 天文データ（astro_tasker）

スマホのブラウザ（または Tasker の WebView）で開く、1枚の HTML の天文アプリ。
場所は平群町に固定してある（`initLoc()` の座標）。

- 太陽・月・惑星・一等星の方角と高度、出・南中・没の時刻、薄明の時刻
- 太陽と月の1日の高度グラフ
- 空のコンパス表示（上の帯）と、全画面の **VR モード**（スマホを空に向けると、その方向の空が出る）

## 置き場所

`/storage/emulated/0/astro_tasker.html`（= `file:///sdcard/astro_tasker.html`）に置いて開く。

GitHub から入れ替えるとき（PC 不要）:

1. ブラウザで GitHub の `othermarrow/Claude` を開き、ブランチを選んでから `Code` → `Download ZIP` で
   Download フォルダに保存する。
2. Termux で次を実行する。`Claude-main` は保存された zip の名前に合わせて書き換える
   （ブランチを選んだ場合は `Claude-ブランチ名` になる）。

```bash
termux-setup-storage
pkg install -y unzip
cp /storage/emulated/0/astro_tasker.html /storage/emulated/0/astro_tasker.bak.html
cd ~
unzip -o /storage/emulated/0/Download/Claude-main.zip 'Claude-main/astro_tasker/*'
cp Claude-main/astro_tasker/astro_tasker.html /storage/emulated/0/astro_tasker.html
rm -rf Claude-main
```

1行目の `cp` は、前のファイルを `astro_tasker.bak.html` として残すため。

## VR モードの使い方

1. 上の帯の `⛶ VR` で全画面にする。
2. `⊕ SENSOR` を押すと、スマホの向きで空が動く。**スマホの背面が向いている方向**が画面の真ん中（照準の円）になる。
3. 左下の表示
   - `143° SE +49°`: 照準の方位と高度
   - `MAG −8.1°`: 方位センサー（磁北基準）を使っていて、磁気偏角 8.1°西偏 を補正している
   - `REL`: 北がわからないセンサーしか使えない。下の「合わせ方」で合わせる
   - `CAL ±x°`: 手で合わせた量
4. 合わせ方（方位がずれているとき）
   - 月・惑星・明るい星（昼なら太陽）にスマホの背面を向け、画面の照準の円に入れて `◎ CAL` を押す。
     照準から 20°以内でいちばん近い天体に、方位をぴったり合わせる。
   - 大きくずれていて CAL が `✕ NO TARGET` になるときは、先に画面を左右にドラッグして大まかに合わせてから CAL。
   - SENSOR を切ると、合わせた量は消える。
5. 2本指でズーム、ダブルタップでズームを戻す。SENSOR が切れているときは、ドラッグで方位と高度を動かせる。

## 2026-10 の修正（VR モードを正確にする）

| 問題 | 前のずれ | 直したこと |
|---|---|---|
| 方位を `alpha` だけで出していた | スマホを立てて 10° 傾けて持つだけで 16〜23°、最悪 88° | alpha/beta/gamma から回転行列を作り、背面の向きを視線にする。画面の傾き（ロール）と横持ちにも対応 |
| 高度を `beta−90` で出し、±85°で止めていた | 天頂が見られない | 回転行列から出す。真上も見られる |
| 磁気偏角を使っていなかった（定数は +7.3° で向きも逆） | 約 8° | 平群町の値 −8.1°（WMM2025）で真北に直す |
| 平滑化の不感帯で、少しの動きを無視していた | 止めても 1〜2° ずれたまま、30°/秒で回すと 7° 遅れる | 1€フィルタに変更。止めればセンサーの値に戻る（ノイズ 0.5° のシミュレーションで、止めたときの揺れ 0.08°、90°振って止めてから 0.08 秒で 0.5° 以内） |
| 天体の位置を 1時間に1回しか計算していなかった | 最大 15° | 空の表示用は 10 秒ごとに計算する |
| 天体と目盛りで投影の式が違った | VR では高度 30° の天体が 15° の線より下に描かれていた | 地平線・高度線・方位線・黄道・天体をすべて同じ中心投影で描く |
| 火星の軌道要素の取り違え（近日点黄経） | 最大 16° | JPL の近似軌道要素（1800–2050年用、変化率つき）にそろえる |
| 恒星・惑星が J2000 の座標のまま | 約 0.3° | 歳差を計算して観測日の座標にする |
| 月の視差を入れていなかった | 最大 約 1° | 観測地点から見た高度にする |
| 大気差 | 地平線近くで 約 0.5° | 空の表示（VR・コンパス）だけ、見かけの高度で描く。下の一覧の高度は大気差なし |

天体の位置は PyEphem（XEphem の計算部分）と比べて確かめた。2026〜2027年の5つの日時で、
太陽・月・7惑星・一等星21個のずれは最大 4.6′（土星）、ほかは 2.4′ 以内。

## 確認したこと・していないこと

- 確認済み: 上の天体位置の比較。端末の向きの計算（Chrome と同じ方法で作った alpha/beta/gamma から、
  縦持ち・横持ちとも誤差 0.00001°以下で背面の向きが出る）。ヘッドレスの Chromium で、
  センサーのイベントを送ると狙った天体が照準の真ん中に来ること、CAL・ドラッグで合わせられること。
- 未確認: Xperia 1 IV の実機と Tasker の WebView での動き。とくに `deviceorientationabsolute`
  が届くか（届けば左下が `MAG`、届かなければ `REL` と出る）。
