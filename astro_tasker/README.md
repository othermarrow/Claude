# 天文データ（astro_tasker）

スマホのブラウザ（または Tasker の WebView）で開く、1枚の HTML の天文アプリ。
場所は平群町に固定してある（`initLoc()` の座標）。

- 太陽・月・惑星・一等星と北極星の方角と高度、出・南中・没の時刻、薄明の時刻
- 太陽と月の1日の高度グラフ
- 空の表示（上の帯）と、全画面の表示。全画面では「見上げる」（スマホを空に向けると、その方向の空が出る）と
  「星座盤」（空ぜんたいを丸く出す）を切り替えられる

見た目は、時計の星図アプリ（`starmap/`）に合わせている。

## ファイル

| ファイル | 中身 |
|---|---|
| `astro_tasker.html` | Tasker から開く版（`file:///sdcard/astro_tasker.html`） |
| `index.html` | ホーム画面に置く版（PWA）。中身は `astro_tasker.html` と同じ |
| `manifest.json`・`sw.js` | PWA の設定と、ネットがないときのための保存（`index.html` と同じ場所に置く） |
| `LICENSE-d3-celestial.txt` | 星座線のデータ（d3-celestial）のライセンス |

`astro_tasker.html` を直したら、`index.html` にも同じものをコピーする。
`sw.js` はページを先にネットから取るので、更新はすぐ反映される（ネットがないときだけ保存したものを出す）。

## 置き場所（Tasker 版）

`/storage/emulated/0/astro_tasker.html`（= `file:///sdcard/astro_tasker.html`）に置いて開く。

GitHub から入れ替えるとき（PC 不要）:

1. ブラウザで GitHub の `othermarrow/Claude` を開き、ブランチを選んでから `Code` → `Download ZIP` で
   Download フォルダに保存する。
2. Termux で次を実行する。`Claude-main` は保存された zip の名前に合わせて書き換える
   （ブランチを選んだ場合は `Claude-ブランチ名` になる）。

```bash
termux-setup-storage
pkg install -y unzip
cp /storage/emulated/0/astro_tasker.html /storage/emulated/0/astro_tasker.bak.html
cd ~
unzip -o /storage/emulated/0/Download/Claude-main.zip 'Claude-main/astro_tasker/*'
cp Claude-main/astro_tasker/astro_tasker.html /storage/emulated/0/astro_tasker.html
rm -rf Claude-main
```

1行目の `cp` は、前のファイルを `astro_tasker.bak.html` として残すため。
PWA 版は、`index.html`・`manifest.json`・`sw.js` の3つを、今置いている場所に同じように上書きする。

## 空の表示の使い方

- 上の帯: 指で左右・上下に動かす。2本指で拡大、ダブルタップで元に戻す。`↕ 広げる` で帯を高くする。
- `⛶ 全画面` で全画面にする。下のボタンは次のとおり。
  - `◎ 星座盤` / `◎ 見上げる`: 空ぜんたいの円（星座盤）と、見上げた空を切り替える。
    星座盤は真ん中が天頂、外の円が地平線、上が向いている方向。指で左右に動かすと回る。
  - `⊕ センサー`: スマホの向きで空が動く。**スマホの背面が向いている方向**が画面の真ん中（照準の円）になる。
    星座盤のときは、スマホを水平に持つと画面の上の向き、立てると背面の向きが「上」になる。
  - `◎ 合わせる`: 方位がずれているときに使う（下を参照）。
  - `✕ 閉じる`
- 左下の表示
  - `南南西 200° 高さ +20°`: 照準（画面の真ん中）の方位と高さ
  - `方位センサー（偏角 −8.1°）`: 北のわかる方位センサーを使っていて、磁気偏角 8.1°西偏 を補正している
  - `相対センサー（北がわからない）`: 北のわからないセンサーしか使えない。下の「合わせ方」で合わせる
  - `合わせ ±x°`: 手で合わせた量
- 合わせ方（方位がずれているとき）
  - 月・惑星・明るい星（昼なら太陽）にスマホの背面を向け、照準の円に入れて `◎ 合わせる` を押す。
    照準から 20°以内でいちばん近い天体に、方位をぴったり合わせる。
  - 大きくずれていて `✕ 近くに天体なし` になるときは、先に画面を左右にドラッグして大まかに合わせてから押す。
  - センサーを切ると、合わせた量は消える。

## 2026-10 の修正 その2（見やすくする）

時計の星図アプリを手本にした。

| 場所 | 前 | 今 |
|---|---|---|
| 空の表示 | 青いグラデーションの空に、7〜9px の小さな英語の文字。星座線なし | 濃紺の平らな空と黒い地面、水色の地平線、オレンジの黄道。56星座の星座線と 3.5等より明るい星の点（d3-celestial のデータ）。名前は日本語で、重ならない場所にだけ出す |
| 天体の印 | 小さな点と英語名 | 太陽は黄色の円、月は満ち欠けの形（明るい側が太陽の方向、`月 15%`）、惑星は色つきの点、明るい星は星の形（明るいほど大きい） |
| 方位 | `SE`・`SSW` など16方位の小さな文字 | `北`・`東`・`南`・`西` を大きく、`北東` などを中くらいで地平線の上に |
| 全画面 | 見上げる画面だけ | `星座盤` を追加（空ぜんたいを1つの円で） |
| ボタン | `SENSOR`・`CAL`・`EXPAND`・`VR`（9px） | `センサー`・`合わせる`・`広げる`・`全画面`・`閉じる`（13px、押しやすい大きさ） |
| 一覧 | 地平線の下の天体は背景とほぼ同じ色で読めない。薄明の表は 7px | 文字を大きくし、うすい文字も明るくした。地平線の下は「― 地平線の下 ―」の下に、少し暗い色で読めるように。薄明の表は 13〜16px。北極星を追加 |
| 1日のグラフ | 出・没の時刻が地平線のところで重なる。真夜中をまたぐ月の線が、グラフを横切る直線になっていた | 太陽は1段目、月は2段目に分けた。南中が近いときは横にずらす。24時の点が左端に戻っていたのを直した |

速さ: パソコンの Chromium で CPU を 4 倍遅くして測ると、1回の描画は上の帯 11ms、全画面 13ms、星座盤 11ms
（30 コマ/秒に必要な 33ms 以内）。

## 2026-10 の修正 その1（VR モードを正確にする）

| 問題 | 前のずれ | 直したこと |
|---|---|---|
| 方位を `alpha` だけで出していた | スマホを立てて 10° 傾けて持つだけで 16〜23°、最悪 88° | alpha/beta/gamma から回転行列を作り、背面の向きを視線にする。画面の傾き（ロール）と横持ちにも対応 |
| 高度を `beta−90` で出し、±85°で止めていた | 天頂が見られない | 回転行列から出す。真上も見られる |
| 磁気偏角を使っていなかった（定数は +7.3° で向きも逆） | 約 8° | 平群町の値 −8.1°（WMM2025）で真北に直す |
| 平滑化の不感帯で、少しの動きを無視していた | 止めても 1〜2° ずれたまま、30°/秒で回すと 7° 遅れる | 1€フィルタに変更。止めればセンサーの値に戻る（ノイズ 0.5° のシミュレーションで、止めたときの揺れ 0.08°、90°振って止めてから 0.08 秒で 0.5° 以内） |
| 天体の位置を 1時間に1回しか計算していなかった | 最大 15° | 空の表示用は 10 秒ごとに計算する |
| 天体と目盛りで投影の式が違った | VR では高度 30° の天体が 15° の線より下に描かれていた | 地平線・高度線・方位線・黄道・天体をすべて同じ中心投影で描く |
| 火星の軌道要素の取り違え（近日点黄経） | 最大 16° | JPL の近似軌道要素（1800–2050年用、変化率つき）にそろえる |
| 恒星・惑星が J2000 の座標のまま | 約 0.3° | 歳差を計算して観測日の座標にする（星座線の星も同じ） |
| 月の視差を入れていなかった | 最大 約 1° | 観測地点から見た高度にする |
| 大気差 | 地平線近くで 約 0.5° | 空の表示だけ、見かけの高度で描く。下の一覧の高度は大気差なし |

天体の位置は PyEphem（XEphem の計算部分）と比べて確かめた。2026〜2027年の5つの日時で、
太陽・月・7惑星・一等星21個のずれは最大 4.6′（土星）、ほかは 2.4′ 以内。

## 確認したこと・していないこと

- 確認済み（パソコンの Chromium で、スマホと同じ画面の大きさにして）:
  - 上の天体位置の比較。星座線の星の点が、名前のある星（ベテルギウス・リゲル・ベガなど）と同じ場所に出ること。
  - 端末の向きの計算（Chrome と同じ方法で作った alpha/beta/gamma から、縦持ち・横持ちとも誤差 0.00001°以下で背面の向きが出る）。
  - センサーのイベントを送ると狙った天体が照準の真ん中に来ること、`合わせる`・ドラッグで合わせられること（見た目を変えたあとも同じ）。
  - 三日月の明るい側が、地平線の下の太陽の方向を向くこと（見上げる画面・星座盤の両方）。
  - いろいろな日付の1日のグラフで、線が横切らず、時刻の文字が重ならないこと。
- 未確認: Xperia 1 IV の実機と Tasker の WebView での動きと見え方。とくに `deviceorientationabsolute`
  が届くか（届けば左下が「方位センサー」、届かなければ「相対センサー」と出る）。PWA 版の更新とオフラインでの動き。
