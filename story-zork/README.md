# 六一三号室(story-zork)

自分が書いてきた 251 作品の物語の「中身」だけを素材にした、Zork + Backrooms 風のテキストアドベンチャー。
読みかけの紙と紙のあいだから、どこまでも続く黄色い部屋(Level 0)へすり抜けてしまったところから始まる。
自分の名前は思い出せず、番号(613)しか出てこない。名前は「音・色・味・声」の四つのかけらに割れて、あちこちの階層に落ちている。
どこへでも抜けられる近道の部屋「六一三号室」を拠点に、かけらを集めて名札の窪みにはめ、最後に名乗るか伏せるかを決めると、外へ出られる。

見た目と操作は `brain-zork/`・`mirror-zork/` と同じ黄色い部屋で、「命令を作る」と十字キーで遊べる。

## 素材の使い方

- 使ったのは物語の本文の中身だけ。物語の題名、ユーザー名、投稿サイトの名前は使っていない。
- 文章はそのまま使わず、言い換えている(鳥のくり返す一言など、ごく短い決まり文句だけ残したところがある)。
- 一つの物語を一つの部屋に割り当てるのではなく、部屋・物・声・待ったときの様子・黄色い部屋の切れはしに、たくさんの物語の像を混ぜている。
- 自殺・性暴力・虐待・殺人が中心になっている物語は使っていない。施設の職員としての経験に近い物語も、場面としては使っていない。

## 階層としくみ

| 階層 | 場所 | すること |
|---|---|---|
| Level 0 | 黄色い部屋 | 部屋は毎回ちがい、壁や床に物語の切れはしが混ざっている。鳴っている公衆電話に出て、東へ三つ続けて進むと 613 の戸に出る |
| Level 1 | 六一三号室(安全地帯) | 入ると正気度が戻る。北のクローゼット・東の浴室・西のベランダは、それぞれ別の階層につながっている。壁の名札にかけらをはめる |
| Level 2 | 終わらない廊下・音楽室・昇降口 | 廊下は、非常ベルを押して避難訓練をやり終えるまで、同じ所に戻ってくる。訓練中は〈クモ〉〈イヌ〉〈ヒトデ〉が「おさない・はしらない・しゃべらない」を守らせる(列に並んで待つ)。音楽室では、手紙のとおりに和音を弾くと、押す人によって音の違う白鍵が見つかる(「音」)。昇降口では、下駄箱の紙を読み、落ちた消しゴムを拾うと鍵が手に残る。理科室の鍵穴は覗かないほうがいい |
| Level 3 | 冥界の喫茶店 | 紅茶を注ぎ、レモンで色を引き、蜂蜜で色を戻してから飲むと「味」が戻る。順番を間違えると、店主が新しいカップを出す。長居すると、店主がエプロンを差し出してくる |
| Level 4 | 屋上 | 新月の夜。レモンの木から実をもげる。昇降口の鍵で端末の錠を開けて覗くと、色の欄が空いた星(新月)が見つかる(「色」) |
| 出口 | 六一三号室の名札 | 三つはめると黒電話が鳴る。出て、「おやすみ」と言うと「声」が戻る。四つそろったら「名乗る」か「伏せる」。名乗った中身はどこにも保存されない |

「正気度」は、黄色い部屋をさまよう、避難訓練の決まりを破る、鍵穴を覗く、開けてはいけないものを開ける、などで減る。
0 になっても死にはせず、六一三号室(まだ行っていなければ黄色い部屋)で目を覚ます。

## 遊び方

- claude.ai のページ(本人だけが開ける。Chrome の「ホーム画面に追加」でアプリのように起動できる)
- Tasker のシーンで遊ぶときは `story-zork-standalone.html` を Webビューで開く。
  手順は `zork-ja/README.md` の「Tasker のシーンで遊ぶ」と同じで、置き場所だけ変える。

```bash
mkdir -p /storage/emulated/0/Tasker/story-zork
cp /storage/emulated/0/Download/story-zork-standalone.html /storage/emulated/0/Tasker/story-zork/story-zork.html
```

Webビューの「電話へのアクセスを許可」をオンにすると、途中の状態が
`Tasker/story-zork/story-zork-data.json` に残る(Tasker の変数 `%STORYZORK` も使う)。

## ファイル

| ファイル | 役割 |
|---|---|
| `story-zork.html` | ゲーム本体(claude.ai に公開する形) |
| `build.py` | `story-zork-standalone.html`(Tasker やブラウザで直接開く形)を作る |
| `story-zork-standalone.html` | Tasker のシーン用 |

物語のアーカイブ本体と、読むときに作ったメモは、このリポジトリには入れていない。

## 確認できていること・いないこと

- 開発環境の Chromium(スマホの画面サイズ)で、黄色い部屋から四つのかけらを集めて脱出するまで通しで遊べた(名乗る・伏せるの両方)。
  避難訓練のやり直し、紅茶の順番違い、正気度が 0 になったときの戻り先、「命令を作る」・日本語の命令・英語の命令・続きから再開が動いた。
- Tasker の実機と claude.ai の中では、まだ確かめていない。
