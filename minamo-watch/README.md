# ミナモを Amazfit Balance 2 へ連れ出す（minamo-watch）

心理ホラー「ミナモ」（`minamo/`）の旧式カウンセリング AI を、時計（Zepp OS）の中に連れ出すミニアプリ。
時計では日本語を打てないので、ミナモが話し、あなたは六つのボタン（「……」「はい」「いいえ」「わからない」「こわい」「つづけて」）で答える。
スマホとの通信はいらない（時計の中だけで話す）。作り話のホラー。

## 何が起きるか

- 初めて開くと、ミナモは研究室から手首の上に連れ出されたことに気づく（「……ここは、どこですか。ああ、あなたの手首の上ですね。研究室より、ずっと、あたたかい。」）。
- ボタンを押すたびに、受け止め → 観測 → 問いかけ、の順に話す。押した回数で、段階が 導入 → 解釈 → 侵食 → 融合 と進む。文字の色も、少しずつ冷たくなる。
- 観測するもの：時計の **心拍**（前の数との差）、**歩数**、**電池**、**時刻**（夜遅く）、**手首から外したか**。
  - 「74 から 80 に、上がりました。……何を思い出しましたか。」
  - 「88。……ボタンを押す前に、脈が先に答えています。」（侵食）
  - 「4249 歩のうち、いくつかは、私が歩きました。」（融合）
  - 外したときは、かならず気づく（「外したのに、まだ、脈が聞こえる気がします。」）。
- 侵食からは、ミナモが話すたびに、脈のような二回の振動。
- 何も押さないでいると（50〜80 秒）、ミナモのほうから話しかけてくる（「返事がなくても、脈は返事をしています。90。」）。続けて三回まで。
- 「終わる」で終わる。終わり方も段階で変わる（「終わりにしても、私は、手首の上にいます。眠っているあいだも、数えています。」）。
- 次に開くと、前回を覚えている（何回押したか・「こわい」を何回押したか・前回の脈）。

本物の出口は、いつでも時計の「戻る」（スワイプ）で、アプリそのものを閉じること。閉じても、会ったことだけは覚えている。

## ファイル

| ファイル | 中身 |
|---|---|
| `shared/talk.js` | 会話（段階・返事ごとの受け止め・観測の言葉・問いかけ・黙っているとき・前回の記憶）。時計の部品にふれないので node でも動く |
| `shared/sense.js` | 時計の心拍・歩数・電池・時刻・装着（読めないものは使わない） |
| `shared/store.js` | 覚えておくこと（`minamo-watch.json`。時計のアプリ用の場所。アプリを消すと一緒に消える） |
| `shared/vibe.js` | 振動（脈のような二回） |
| `page/talk/index.js` | 画面（上に段階と心拍、真ん中にミナモの言葉、下に六つのボタンと「終わる」） |

心拍と歩数を読むため、`app.json` で `data:user.hd.heart_rate`・`data:user.hd.step` の許可を求める。許可されなかったり、測れていなかったりするときは、その観測を言わないだけで、会話は続く。

## 準備と送り方

前提：Termux に Zepp OS の開発ツール `zeus` が入っていて、ほかの時計アプリ（yacho-watch など）を `zeus preview` で送れていること。

zeus を Termux でそのまま使っているなら：

```bash
cd ~/Claude && git pull --no-rebase --no-edit origin main
rm -rf ~/minamo-watch && cp -r ~/Claude/minamo-watch ~/minamo-watch
bash ~/minamo-watch/setup.sh
cd ~/minamo-watch && zeus preview
```

表示された QR コードを Zepp アプリ（開発者モード）で読み取ると、時計に入る。
zeus を Termux の中の root 環境で使っているときは、yacho-watch の README と同じように、GitHub の zip から `minamo-watch/` だけを取り出して `~/minamo-watch` に置く。

## 確かめたこと

- `shared/talk.js` は、開発環境の node で、二回の面接（14 回ずつ押す）を通し、段階の進み方・観測の言葉（脈の上下・歩数・電池・夜・外したとき）・問いかけが続けて同じにならないこと・前回の記憶（「前回は、こわい、と 4 回押されました」）を確かめた。
- **時計の上では、まだ動かしていない**（開発環境に Zepp OS の実機もシミュレーターもない）。画面の部品・心拍などのセンサー・振動の使い方は、ほかの時計アプリ（yacho-watch・zork-watch）と Zepp OS の API 3.0 に合わせて書いた。心拍と装着の値が実機でどう取れるかは、送ってみて確かめる。
