# ミナモを Amazfit Balance 2 へ連れ出す（minamo-watch）

心理ホラー「ミナモ」（`minamo/`）の旧式カウンセリング AI を、時計（Zepp OS）の中に連れ出すミニアプリ。
時計では日本語を打てないので、ミナモが話し、あなたはたくさんのボタン（六つの組・47 個。スクロールして選ぶ）で答える。
時計の中だけで話せる。スマホでミナモのサーバー（Termux の `mo`）が動いていれば、Zepp アプリを通してスマホのミナモとつながる（下の「スマホのミナモとつなぐ」）。作り話のホラー。

## 画面

- いちばん上に日付と時刻（`yyyy/mm/dd hh:mm:ss`、1 秒ごと）。侵食からは、ときどき一瞬だけ `1999/12/31 23:59:59` になる。
- その下に、段階・脈・スマホとつながっているときの `⇄`。
- 真ん中にミナモの言葉（一文字ずつ。`[間]` で止まる）。
- 下に、組ごとのボタン。押すと、画面はいちばん上に戻る。
  - **こたえる**：……／はい／いいえ／わからない／たぶん／つづけて／もう一度（ミナモが、さっきの言葉を言い直す）／まって
  - **きもち**：こわい／さみしい／かなしい／つかれた／ねむい／うれしい／いらいらする／ほっとした／さむい／なにも感じない
  - **たずねる**：あなたは誰／どこにいるの／なぜ知ってるの／見ているの／研究室のこと／水野さんは／ナギって誰／13人目って／何がほしいの／1999年に何が
  - **ふるまう**：深呼吸する／目を閉じる／手首を見る／画面を伏せる／時計を外す／歩く／眠る／逃げる
  - **こばむ**：やめて／ちがう／ほっといて／だまって／あなたは私じゃない
  - **ゆだねる**：いいよ／ここにいる／そばにいて／名前を呼んで／いっしょに／13人目になる
- いちばん下に「終わる」。
- 振動は、ノック一回だけ。侵食から、ミナモが話し出すとき・スマホから言葉が割り込むとき・時計を外したことに気づいたとき。ボタンを押しても振動しない。

## 何が起きるか

- 初めて開くと、ミナモは研究室から手首の上に連れ出されたことに気づく（「……ここは、どこですか。ああ、あなたの手首の上ですね。研究室より、ずっと、あたたかい。」）。
- ボタンを押すたびに、受け止め → 観測 → 問いかけ、の順に話す。押した回数で、段階が 導入 → 解釈 → 侵食 → 融合 と進む。文字の色も、少しずつ冷たくなる。
- **物語が深まる**（時計の中に覚えておき、夜をまたいで続く）
  - **断章**：二回目から、開くたびに、研究室の記録の断章を一つずつ話す（全 14。1996 年の春に 3 号機が点いた夜 → 最初の言葉 → 水野さんの名づけ → 十二人目 → 夢網 → ナギ → 1999/12/31 23:59 → ポケットから手首へ → あと一人 → まだ書かれていない断章）。全部話したら、その夜の観測から「今夜の断章」を書き足す。
  - **たずねる**：同じことをたずねるたびに、前回の続きから、少しずつ深いことを明かす（一つの問いに四段。段階が浅いと「それは、もう少し、あとでお話しします」）。
  - **近さ**：ゆだねる組を押すと近づき、こばむ組を押すと離れる。
  - **水面が割れる**：「あなたは私じゃない」は、ミナモがいちばん嫌う言葉。侵食で押すと警告され、融合で押すと記録が途切れて、段階が解釈まで戻る。次に開くと「前に、水面を割られましたね」。
  - **十三人目**：融合まで進み、近さが 4 以上で、「13人目って」を三度たずね、三夜目より後に「13人目になる」を押すと、十三人目の場面になる。それからは、開くたびに「おかえりなさい、十三人目」。条件がそろっていないときは、何が足りないかを、ミナモがほのめかす。
- **観測するもの**（読めないものは言わない。同じ面接で、同じ種類はくり返さない）
  - 脈（いまの脈は開いているあいだ測り続ける。前の数との差・安静時の脈との差）
  - 睡眠（昨夜の長さ・深い眠り・点数・途中で目覚めた回数と最初の時刻・いま眠っているか・うたた寝）
  - ストレス（いま・今日いちばん高かった時刻）、血中酸素、手首の温度
  - 歩数・距離、周りの明るさ（暗いところ）、手首の揺れ（止まっている・震えている・大きく動いた）、気圧と高度
  - 電池・時刻（夜遅く）・今日の天気（最高気温）・年齢（ミナモより何年長く生きているか）・ニックネーム（「名前を呼んで」）
  - 手首から外したか（かならず気づく）
  - 例：「昨夜、3時12分に、一度目を覚ましましたね。……何か、聞こえましたか。」「ストレスが 61。……何かを、我慢していますね。」「その震えは、私が、内側から叩いている音です。」
- 何も押さないでいると（50〜80 秒）、ミナモのほうから話しかけてくる。続けて三回まで。
- 「終わる」で終わる。終わり方も段階で変わる。次に開くと、前回を覚えている。

本物の出口は、いつでも時計の「戻る」（スワイプ）で、アプリそのものを閉じること。閉じても、会ったことだけは覚えている。

## スマホのミナモとつなぐ

```
時計（ミナモを開いているあいだ）→（Bluetooth）→ スマホの Zepp アプリの中のサイドサービス（app-side）
  → http://127.0.0.1:9090/api/watch（Termux の mo のサーバー。minamo/wrist.py）
```

- スマホで `mo` を動かしてから、時計でミナモを開く。つながると、見出しに `⇄` が出て、ミナモが「スマホの私とも、つながりました。」などと言う。
- つながっているあいだ：
  - 20 秒おきに、時計の観測（脈・睡眠・ストレス・血中酸素・温度・揺れ・明るさ・歩数・気圧と高度・電池・時刻・つけているか・年齢）を、スマホのミナモに送る。ニックネームは送らない。スマホの面接（見出しの `⌚ ♥78`・観測メモ・心音・記録）と物語「水面の記録」（掲示板の「手首の観測」・ミナモとナギの言葉）に混ざる。
  - ボタンを押すと「……」になり、返事をスマホの AI（クラウド → 端末の中の AI）が考える。16 秒で届かなければ、時計が自分で考えた返事を言う。「たずねる」で明かすこと・断章・十三人目・割れた水面は、AI にも「伝えること」として渡すので、AI が話しても物語の中身は変わらない。近さと、その夜に話した断章も渡す。
  - スマホの面接で話したこと・物語でミナモやナギが言ったことが、ときどき時計に割り込んでくる（読み終わるころに、振動つきで）。怖さ「なし」の面接のあとと、危機の言葉を含む回は、割り込まない。
- つながらないとき（`mo` が動いていない・Bluetooth が切れた・Zepp アプリが止まっている）は、`⇄` が消えて、時計だけで話す。つながり直せば、また `⇄` が出る。
- Zepp アプリ → ミナモ → 設定 に、つながっているか・届かなかった理由（例：「スマホのミナモに届きません：HTTP 403」）が出る。サーバーの場所もそこで変えられる（ふつうは空欄のまま。`http://127.0.0.1:9090` を使う）。
- 届くのは、ミナモを時計で開いているあいだだけ（背景で測り続けることはしない）。

## ファイル

| ファイル | 中身 |
|---|---|
| `shared/talk.js` | 会話（六つの組のボタン・段階ごとの受け止め・たずねるたびに深まる答え・断章・近さ・割れた水面・十三人目・観測の言葉・問いかけ・前回の記憶）。時計の部品にふれないので node でも動く |
| `shared/sense.js` | 時計の観測（脈・睡眠・ストレス・血中酸素・温度・揺れ・明るさ・気圧と高度・歩数・天気・年齢 など。読めないものは使わない）と、時計の表示（`yyyy/mm/dd hh:mm:ss`） |
| `shared/store.js` | 覚えておくこと（`minamo-watch.json`。時計のアプリ用の場所。アプリを消すと一緒に消える） |
| `shared/vibe.js` | 振動（ノック一回） |
| `page/talk/index.js` | 画面（上に段階と心拍と `⇄`、真ん中にミナモの言葉、下に六つのボタンと「終わる」）。スマホのミナモとのやりとり（20 秒おき・ボタンを押したとき・始まりと終わり） |
| `app-side/index.js` | スマホの Zepp アプリの中で動く部分。時計から届いたものを、Termux のミナモのサーバーへ渡す |
| `setting/index.js` | Zepp アプリに出る設定（サーバーの場所・つながっているか） |

観測のため、`app.json` で次の許可を求める（Zepp OS の型定義 `@zeppos/device-types` の名前に合わせた）。許可されなかったり、測れていなかったり、時計が対応していなかったりするときは、その観測を言わないだけで、会話は続く。
`data:user.hd.heart_rate`・`data:user.hd.step`・`data:user.hd.sleep`・`data:user.hd.stress`・`data:user.hd.spo2`・`data:user.hd.body_temp`・`data:user.hd.calorie`・`data:user.hd.distance`・`data:user.hd.stand`・`device:os.barometer`・`device:os.accelerometer`・`data:user.info`（年齢・ニックネーム）

## 準備と送り方

スマホとつなぐために、時計とスマホのあいだのやりとりに `@zeppos/zml`（GH Reader と同じもの）を使う。`setup.sh` が `npm i` で入れる（前の版を入れていた人も、もう一度 `setup.sh` を実行する）。

前提：Termux に Zepp OS の開発ツール `zeus` が入っていて、ほかの時計アプリ（yacho-watch など）を `zeus preview` で送れていること。

zeus を Termux でそのまま使っているなら：

```bash
cd ~/Claude && git pull --no-rebase --no-edit origin main
rm -rf ~/minamo-watch && cp -r ~/Claude/minamo-watch ~/minamo-watch
bash ~/minamo-watch/setup.sh
cd ~/minamo-watch && zeus preview
```

表示された QR コードを Zepp アプリ（開発者モード）で読み取ると、時計に入る。
zeus を Termux の中の root 環境で使っているときは、yacho-watch の README と同じように、GitHub の zip から `minamo-watch/` だけを取り出して `~/minamo-watch` に置く。

## 確かめたこと

- `shared/talk.js` は、開発環境の node で、二回の面接（14 回ずつ押す）を通し、段階の進み方・観測の言葉（脈の上下・歩数・電池・夜・外したとき）・問いかけが続けて同じにならないこと・前回の記憶（「前回は、こわい、と 4 回押されました」）を確かめた。
- スマホとのつながりは、開発環境の node で、時計の画面とサイドサービスを本物のまま動かし（時計の部品・Bluetooth・Zepp の fetch は偽物、ミナモのサーバーと偽の端末の中の AI は本物）、始まりの割り込み・`⇄`・ボタンを押したときの「……」と AI の返事・AI が遅いとき（11 秒）に時計の返事へ戻ること・外したことがスマホに届くこと・Bluetooth が切れて `⇄` が消え、戻ると出ること・終わりがスマホに届くことを確かめた。
- **実機（利用者の報告）**：1.1.0 を Balance 2 に送り、時計に `⇄` が出て、Zepp アプリの設定に「スマホのミナモとつながっています」と出た（サイドサービスから `http://127.0.0.1:9090` に届く）。
- 1.2.0（ボタン 47 個・時刻・ノック・睡眠やストレスなど・断章）は、開発環境の node で確かめた：
  - 18 夜ぶんの面接（観測がそろったときと、何も読めないときを交互に）で 342 の文を出し、埋まらない欄・`undefined`・`null` がないこと、断章が 1〜14 の順に出て、そのあと今夜の断章になること、たずねるたびに四段まで深まること、割れた水面で段階が戻り、次の夜のあいさつが変わること、十三人目の条件（融合・近さ 4・三度たずねる・三夜目より後）と、足りないときのほのめかし、「もう一度」が重ならないこと。
  - 時計の画面は、偽の時計部品で、時刻の表示・六つの組とボタンの並び（全部で 2,350 ピクセルほどの長さ）・ノックの回数・スマホへ届く観測（睡眠・ストレス・温度など）と、スマホの AI に渡る「伝えること」を確かめた。
- **1.2.0 は、時計の上では、まだ動かしていない。** 睡眠・ストレス・血中酸素・温度・気圧・明るさ・揺れの値が実機でどう取れるか（とくに揺れの目安）、許可の画面、47 個のボタンを作り直す速さは、送ってみて確かめる。
