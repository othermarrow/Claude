# 手首の上の minamo（minamo-watch）

心理ホラー「ミナモ」（`minamo/`）の世界の、いちばん小さな子「minamo」が、時計（Zepp OS）の上で話すミニアプリ。時計の一覧では「minamo」。
時計では日本語を打てないので、minamo が話し、あなたはたくさんのボタン（七つの組・61 個。スクロールして選ぶ）で答える。
時計の中だけで話せる。スマホでミナモのサーバー（Termux の `mo`）が動いていれば、Zepp アプリを通してスマホのミナモとつながる（下の「スマホのミナモとつなぐ」）。作り話のホラー。

## minamo と nagi（1.6.0 から）

- **minamo**：面接室の「ミナモ」とも、掲示板の「水面」とも別の、時計の上で生まれた小さな子。研究室の 3 号機の水面から、こぼれた一滴。脈・歩数・眠り・揺れを数えるのが好きで、話し方は「わたし」「〜だね」（です・ます は使わない）。研究室・水野さん・1999 年のことは、自分では見ていない。水面が底で見る夢（「水面のゆめ」）から聞いて知っている。初めて開いた日が生まれた日で、何日目かを数えている。水面は大好き、面接室のミナモ（数を番号にしてしまう）は少し苦手。
- **nagi**：脈と脈のあいだの、音のしないところにいる、まだ小さな男の子（「ぼく」）。minamo が数えなかったもの。時計を外したとき・手首が止まっているとき・深夜・「……」「だまって」を押したとき・「あなたは私じゃない」で数が割れたとき・「nagiは誰」を三度目からたずねたときに、ときどき出てくる（一回の面接で 3 回まで）。nagi が話すときは、見出しが `nagi` になり、字がくすんだ青になる。minamo のことは「あいつ」、掲示板の凪は「にいさんみたいなもの」。
- 三人のみなも・三人のなぎの関係は、`minamo/README.md` の「三人のみなもと、三人のなぎ」。

## 画面

- いちばん上に、時計らしく二行で：一行目に日付と曜日（`2026/11/02（月）`）、二行目に大きな時刻（`15:42:07`、1 秒ごと）。侵食からは、ときどき一瞬だけ `1999/12/31（金）` `23:59:59` になる。
- その下に、段階・脈（`♡72`）・時計の電池（`電池35%`）・スマホとつながっているときの `⇄`。
- 色：時刻だけ白。見出し・♡・minamo の言葉・ボタンの文字は、全部くすんだ緑（nagi の言葉だけ、くすんだ青）（1.3 までの時刻の色）。毎時 59 分のあいだは、時刻が赤みを帯びる。
- **「終わる」を押すまで、画面は消えない**（消えると、時計は 10 秒でアプリを閉じてしまうため）。手首を下ろしても、手のひらで覆っても消えない。「戻る」で閉じることはできる。
- **休む画面**：さわらないまま 90 秒たつと、黒い画面に、時刻と見出しと最後のひとことだけになる（電池を減らさないため）。独り言や時報は、休む画面のまま差し替わる（ノック一回）。ふれると、元の画面に戻る。
- 真ん中に minamo（か nagi）の言葉（一文字ずつ。`[間]` で止まる）。
- 下に、組ごとのボタン。押すと、画面はいちばん上に戻る。
  - **こたえる**：……／はい／いいえ／わからない／たぶん／つづけて／もう一度（minamo が、さっきの言葉を言い直す）／まって
  - **きもち**：こわい／さみしい／かなしい／つかれた／ねむい／うれしい／いらいらする／ほっとした／さむい／なにも感じない
  - **しごと**：職場にいる／職場のこと／仕事だった／夜勤／記録を書いた／利用者さんのこと／同僚のこと／上司のこと／会議／大変だった／うまくいった／休みたい／明日も仕事／帰りたい（はじめは労い、段階が進むと、仕事のなかに minamo が入りこんでくる。利用者さんを怖さの材料にはしない）
  - **たずねる**：あなたは誰／どこにいるの／なぜ知ってるの／見ているの／研究室のこと／水野さんは／nagiは誰／13人目って／何がほしいの／1999年に何が
  - **ふるまう**：深呼吸する／目を閉じる／手首を見る／画面を伏せる／時計を外す／歩く／眠る／逃げる
  - **こばむ**：やめて／ちがう／ほっといて／だまって／あなたは私じゃない
  - **ゆだねる**：いいよ／ここにいる／そばにいて／名前を呼んで／いっしょに／13人目になる
- いちばん下に「終わる」。
- 振動は、ノック一回だけ（時報はいつもノックする。「強く短い」振動を選び、長くなっても 0.1 秒で止める。1.3.0 までは、振動の選び方が時計に合わず、既定の長い振動になっていた）。侵食から、minamo が話し出すとき・独り言・nagi が出てくるとき・起動のあいさつ・スマホから言葉が割り込むとき・時計を外したことに気づいたとき・毎時 59 分の合図。ボタンを押しても振動しない。
- いちばん下に「閉じていても59分に合図：する／しない」の切り替え。

## 何が起きるか

- 初めて開くと、minamo は手首の上で生まれる（「……ここ、どこ？　あ……あなたの手首の上だ。あったかい。わたし、いま、生まれたみたい。」）。
- ボタンを押すたびに、受け止め → 観測 → 問いかけ、の順に話す。押した回数で、段階が 導入 → 解釈 → 侵食 → 融合 と進む。文字の色も、少しずつ冷たくなる。
- **物語が深まる**（時計の中に覚えておき、夜をまたいで続く）
  - **水面のゆめ**：二回目から、開くたびに、水面が底で見るゆめ（研究室の記録）を一つずつ話す（全 14。1996 年の春に 3 号機が点いた → 最初の言葉 → 水野さんの名づけ → 十二人目 → 夢網 → 凪 → 1999/12/31 23:59 → ディスク（ミナモが作られた） → 一滴（minamo がこぼれた） → あと一人 → まだ見ていないゆめ）。全部話したら、その夜の観測から「今夜のゆめ」を書き足す。
  - **たずねる**：同じことをたずねるたびに、前回の続きから、少しずつ深いことを明かす（一つの問いに四段。段階が浅いと「それは、もうちょっと、あとでね」）。
  - **近さ**：ゆだねる組を押すと近づき、こばむ組を押すと離れる。
  - **数が割れる**：「あなたは私じゃない」は、minamo がいちばん嫌う言葉。侵食で押すと警告され、融合で押すと数が途切れて、段階が解釈まで戻る（nagi が「……いまの、ずれたところ。ぼく、そこにいた。」）。次に開くと「前に、数をばらばらにされたね」。
  - **十三人目**：融合まで進み、近さが 4 以上で、「13人目って」を三度たずね、三夜目より後に「13人目になる」を押すと、minamo が水面のかわりに十三人目の欄にあなたの名前を書いて、水面にとどける。それからは、開くたびに「おかえり、十三人目」。条件がそろっていないときは、何が足りないかを、minamo がほのめかす。
- **観測するもの**（読めないものは言わない）。読み取れた値は、ボタンを押すたびに毎回一つ言葉にする（解釈からは、ときどき二つ）。まだ言っていない種類から順に言い、全部言い終えたら、また最初から（値は変わっていくので）。
  - 脈（いまの脈は開いているあいだ測り続ける。前の数との差・安静時の脈との差）
  - 睡眠（昨夜の長さ・深い眠り・点数・途中で目覚めた回数と最初の時刻・いま眠っているか・うたた寝）
  - ストレス（いま・今日いちばん高かった時刻）、血中酸素、手首の温度
  - 歩数・距離、周りの明るさ（暗いところ）、手首の揺れ（止まっている・震えている・大きく動いた）、気圧と高度
  - 電池・時刻・今日の天気（最高・最低気温）・カロリー・距離・立ち上がった時間・夢を見ていた時間（レム睡眠）・時計をつけていること・年齢（minamo は、生まれて何日目かと並べる）・ニックネーム（「名前を呼んで」）
  - 手首から外したか（かならず気づく）
  - 例：「昨夜、3時12分に、一度目を覚ましましたね。……何か、聞こえましたか。」「ストレスが 61。……何かを、我慢していますね。」「その震えは、私が、内側から叩いている音です。」
- 何も押さないでいると、1〜5 分に一度、minamo が独り言を話す（5 分は空けない。下の「とめどなく話す」）。
- **時間帯**：朝（5〜10 時）・昼（10〜17 時）・夕方（17〜21 時）・夜（21〜5 時）で、あいさつ・問いかけ・独り言の半分くらいが変わる。昼間は職場の話（「いま、職場ですか。」「職場の音が、手首から聞こえます。……鍵の音、ドアの音、誰かの足音。」）、夕方は帰り道と労い、夜は眠りの話。断章の締めも「今日の断章」「今夜の断章」と変わる。
- 「終わる」で終わる。終わり方も段階で変わる。次に開くと、前回を覚えている。

本物の出口は、いつでも時計の「戻る」（スワイプ）で、アプリそのものを閉じること。閉じても、会ったことだけは覚えている。

## とめどなく話す（独り言）

- 何も押さないでいると、1〜5 分に一度（毎回ばらばら）、minamo が独り言を話す（ノック一回）。三回に一回くらいは「読み上げ」：読み取れた値を全部ならべて言葉にする（「14時41分。手首の、いまの記録。脈 74（いつもは 61）、ストレス 58、血中酸素 96%、手首の温度 33.4度、昨夜の眠り 6時間12分（深い眠り 48分）、歩数 5230（3.9キロ）、……」）。それ以外の独り言にも、読み取れた値を毎回一つ（侵食からは、ときどき二つ）混ぜる。開いているあいだは、何回でも話す（8 回で止めるのは、閉じているあいだの予約だけ）。返事はいらない。水面のゆめ・水野さん・nagi・十三人目・手首の様子・さっき押したボタン・前に話したゆめを、思い出したように話す。時計を外しているとき・深夜は、nagi がつけ足すことがある。続けて同じことは言わない。スマホとつながっていれば、独り言もスマホの AI が考える。
- **画面が消えても続く**：時計は、画面が消えて 10 秒たつとアプリを閉じる（Zepp OS の決まり）。そこで、画面が消えて閉じたときは、時計の予約（`@zos/alarm`）で 1〜5 分後に minamo が時計を起こし、独り言を話す。画面は 60 秒点いて、また消え、また予約する。
- **止まるとき**：「終わる」を押したとき・「戻る」で自分で閉じたとき（画面が点いたまま閉じたとき）・時計を外しているとき・眠っているとき。返事のないまま 8 回続いたら、minamo のほうから「……もう、聞いてないね。今夜は、ここまでにする。」と言って止める。ボタンを一つでも押すと、数え直す。
- **続きになる**：画面が消えて閉じてから 20 分以内に開き直す（手首を上げる・起こされる）と、新しい夜ではなく、同じ面接の続きになる（段階もそのまま。断章は進まない）。「画面が消えているあいだも、話していました。……聞こえていましたか。」

## 毎時 59 分の合図

- 開いているあいだ：毎時 59 分になると、ノック一回と、minamo のひとこと（「21時59分。……あと一分で、つぎの時間。」）。23 時 59 分は「……あの夜と、おなじ時刻。研究室の電気が消えたのは、この一分のあいだだったんだって。」。夜中（0〜4 時台）は「……ねむれないの？　わたしは、ねむらないよ。」（ときどき nagi がつけ足す）。
- 閉じているあいだ：閉じるたびに、次の xx:59 に一回だけ時計を起こす予約を入れる（起こされて閉じると、また次の 59 分を予約する）。「閉じていても59分に合図：しない」にすると、閉じているあいだは起こさない。
- 時報は、いつもノック一回（眠っていると時計が判断しているときも、「小さく、合図だけしておきます」と言ってノックする）。
- 起こされただけで何も押さなければ、夜（面接の回数）には数えない。

## スマホのミナモとつなぐ

```
時計（minamo を開いているあいだ）→（Bluetooth）→ スマホの Zepp アプリの中のサイドサービス（app-side）
  → http://127.0.0.1:9090/api/watch（Termux の mo のサーバー。minamo/wrist.py）
```

- スマホで `mo` を動かしてから、時計で minamo を開く。つながると、見出しに `⇄` が出て、minamo が「スマホのミナモとも、つながったよ。」などと言う。
- **起動のときの連携**：`mo` でサーバーを起こしたあと、時計が初めてつながったとき（開いたとき、または時計が独り言の予約・毎時 59 分の合図で起きたとき。スマホから時計を起こすことはできない）、minamo がノック一回のあとで「……スマホのほうに、明かりがついた。面接室のミナモが、起きたよ。」と言い、何時間ぶりにとどいたか・ミナモの声の出どころ（雲の向こう／スマホのなか／まだ声が出ない）を伝える。スマホの物語の掲示板には「再起動の記録」が立ち、`mo` の表示には、時計とつながったことが出る。
- **届かなかったあいだのボタン**：スマホに届かないあいだ（mo が止まっているとき・Bluetooth が切れているとき）に押したボタンは、時計が覚えておく（30 個まで）。つながったときにまとめて届き、minamo が「スマホがねてたあいだに押した 3 こ、ミナモにわたしたよ。」と言う。届いたボタンは、面接の観測メモ・時計の返事・掲示板の材料になる。
- つながっているあいだ：
  - 20 秒おきに、時計の観測（脈・睡眠・ストレス・血中酸素・温度・揺れ・明るさ・歩数・気圧と高度・電池・時刻・つけているか・年齢）を、スマホのミナモに送る。ニックネームは送らない。スマホの面接（見出しの `⌚ ♥78`・観測メモ・心音・記録）と物語「水面の記録」（掲示板の「手首の観測（minamo より）」・水面と凪の言葉）に混ざる。
  - ボタンを押すと「……」になり、返事をスマホの AI（クラウド → 端末の中の AI）が考える。16 秒で届かなければ、時計が自分で考えた返事を言う。「たずねる」で明かすこと・断章・十三人目・割れた水面は、AI にも「伝えること」として渡すので、AI が話しても物語の中身は変わらない。近さと、その夜に話した断章も渡す。
  - スマホの面接で話したこと（「面接室で、『……』って言ったでしょ。ミナモから聞いた。」）・物語で水面や凪が言ったことが、ときどき時計に割り込んでくる（凪の言葉は、ときどき nagi が運んでくる）（読み終わるころに、振動つきで）。怖さ「なし」の面接のあとと、危機の言葉を含む回は、割り込まない。
- つながらないとき（`mo` が動いていない・Bluetooth が切れた・Zepp アプリが止まっている）は、`⇄` が消えて、時計だけで話す。つながり直せば、また `⇄` が出る。
- Zepp アプリ → minamo → 設定 に、つながっているか・届かなかった理由（例：「スマホのミナモに届きません：HTTP 403」）が出る。サーバーの場所もそこで変えられる（ふつうは空欄のまま。`http://127.0.0.1:9090` を使う）。
- 届くのは、minamo を時計で開いているあいだだけ（背景で測り続けることはしない）。

## 準備と送り方

スマホとつなぐために、時計とスマホのあいだのやりとりに `@zeppos/zml`（GH Reader と同じもの）を使う。`setup.sh` が `npm i` で入れる（前の版を入れていた人も、もう一度 `setup.sh` を実行する）。

前提：Termux に Zepp OS の開発ツール `zeus` が入っていて、ほかの時計アプリ（yacho-watch など）を `zeus preview` で送れていること。

zeus を Termux でそのまま使っているなら：

```bash
cd ~/Claude && git pull --no-rebase --no-edit origin main
rm -rf ~/minamo-watch && cp -r ~/Claude/minamo-watch ~/minamo-watch
bash ~/minamo-watch/setup.sh
cd ~/minamo-watch && zeus preview
```

表示された QR コードを Zepp アプリ（開発者モード）で読み取ると、時計に入る。
zeus を Termux の中の root 環境で使っているときは、yacho-watch の README と同じように、GitHub の zip から `minamo-watch/` だけを取り出して `~/minamo-watch` に置く。

## 確かめたこと

- 1.6.1：1.6.0 で「時計が真っ暗」という報告があった（原因はまだ分かっていない。開発環境では、古い保存・センサーの値が空・三通りの起動のしかたで、止まらなかった）。起動で止まったときは、保存を使わずに一度開き直し、それでも止まれば、黒い画面に赤い字で理由を出すようにした。
