# 三面鏡(mirror-zork)

三つのAIが書いた「あなたの人物像」だけを素材にした、テキストアドベンチャー。
三枚の鏡それぞれの向こうの部屋で、その鏡が何を映して何を映していないかを確かめ、かけらを一つずつ持ち帰る。
三つ集めると四つ目の鏡が映り、縁にある「どの鏡にも映らなかった五つの欄」を、書くか伏せるか決める。

見た目と操作は Zork 日本語版(`zork-ja/` のブラウザ版)と同じで、「命令を作る」と十字キーで遊べる。
色は青とシアンだけ、枠線なし、本文は明朝体(人物像の中の、見た目の好みの記述に合わせた)。

## 素材

`brain-zork/` とは別に、次の三つの文章だけを使っている。Vault の他のフォルダは使っていない。
文章はそのまま使わず、言い換えている。

| 鏡 | 元の文章 | 映すもの |
|---|---|---|
| 西の鏡(設計図の工房) | ChatGPT の人物像 | 関心を仕組みに変える人。広げるのが速く、閉じるのが少し苦手 |
| 北の鏡(確かめの実験室) | Claude の人物像 | 確かめてから信じる人。目的は動かさず手段を替え、「やめときます。」で畳む |
| 東の鏡(方法論の回廊) | Gemini の人物像 | 性格推定の方法論の報告書。あなたについての一行は、どこにもない |

## 部屋としくみ

- **ドーム**: 星座盤(かざすと月が九十度ずれるので、水平に置いて見る。置くとヒントが出る)と四つの鏡。
- **設計図の工房**: 机の上の構想カードを「今進める」「保存」「保留」の箱に分ける。
  成功の札(今夜の空の方角が画面に出る)を読み、必要な三つだけを「今進める」に入れ、残りは保存か保留へ。
  工房に長くいると構想が増える。組み上がった装置を動かすと、正確さ → 使いにくさ → 好み、の順に直す。
- **確かめの実験室**: 証言台の札六枚を、原文にあたって(確かめる)から「本人の言葉」「くり返し」「AIの解釈」の皿に置く。
  もう一つ、文字おこしの機械。目的の札は動かさず、エンジンを替える。手元のエンジンは熱くなるか憶測を足すので、
  何度か試したら一式を畳み(「やめときます。」)、オンラインのAPIで動かす。
- **方法論の回廊**: 円の図を三つ以上、語数の秤、報告書の最終ページを見て、ペンで余白に書き足す。
- **四つ目の鏡**: かけらが三つ集まると布が落ち、気持ち・人との時間・休み方・楽しみ・自分への点数の五つの欄が出る。
  どれも「書く」か「伏せる」を決めるだけで、書いた中身はどこにも保存されない。

## 遊び方

- claude.ai のページ(本人だけが開ける。Chrome の「ホーム画面に追加」でアプリのように起動できる)
- Tasker のシーンで遊ぶときは `mirror-zork-standalone.html` を Webビューで開く。
  手順は `zork-ja/README.md` の「Tasker のシーンで遊ぶ」と同じで、置き場所だけ変える。

```bash
mkdir -p /storage/emulated/0/Tasker/mirror-zork
cp /storage/emulated/0/Download/mirror-zork-standalone.html /storage/emulated/0/Tasker/mirror-zork/mirror-zork.html
```

Webビューの「電話へのアクセスを許可」をオンにすると、途中の状態が
`Tasker/mirror-zork/mirror-zork-data.json` に残る(Tasker の変数 `%MIRRORZORK` も使う)。

## 確認できていること・いないこと

- 開発環境の Chromium(スマホの画面サイズ)で、三つのかけらを集めて四つ目の鏡に五つの欄を決め、終わるまで通しで遊べた。
  「命令を作る」・日本語の命令・英語の命令・続きから再開が動いた。
- Tasker の実機と claude.ai の中では、まだ確かめていない。
