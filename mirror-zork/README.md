# 三面鏡(mirror-zork)

三つのAIが書いた「あなたの人物像」だけを素材にした、Backrooms 風のテキストアドベンチャー。
人物像の紙の継ぎ目から、どこまでも続く黄色い部屋(Level 0)へすり抜けてしまったところから始まる。
三面鏡の部屋の三枚の鏡は、それぞれ別の階層(Level)につながっている。その鏡が何を映して何を映していないかを確かめ、
かけらを一つずつ持ち帰る。三つ集めると四つ目の鏡が映り、縁にある「どの鏡にも映らなかった五つの欄」を、
書くか伏せるか決めると、鏡の向こうへ脱出できる。

見た目と操作は `brain-zork/`(脳内バックルーム)と同じ黄色い部屋で、「命令を作る」と十字キーで遊べる。

## 素材

`brain-zork/` とは別に、次の三つの文章だけを使っている。Vault の他のフォルダは使っていない。
文章はそのまま使わず、言い換えている。

| 鏡 | 元の文章 | 映すもの |
|---|---|---|
| 西の鏡 → Level 2 構想の倉庫 | ChatGPT の人物像 | 関心を仕組みに変える人。広げるのが速く、閉じるのが少し苦手 |
| 北の鏡 → Level 3 熱い配管室 | Claude の人物像 | 確かめてから信じる人。目的は動かさず手段を替え、「やめときます。」で畳む |
| 東の鏡 → Level 4 方法論のオフィス | Gemini の人物像 | 性格推定の方法論の報告書。あなたについての一行は、どこにもない |

## 階層としくみ

| 階層 | 場所 | すること |
|---|---|---|
| Level 0 | 黄色い部屋 | 壁紙の書き込みを読み、東へ三つ続けて進んで、しみのある壁を「すり抜ける」 |
| Level 1 | 三面鏡の部屋(安全地帯) | 入ると正気度が戻る。星座盤は、水平に置いて読むとヒントが出る。鏡を「すり抜ける」と各階層へ |
| Level 2 | 構想の倉庫 | 成功の札を読み、必要な三つだけを「今進める」箱へ、残りは保存か保留へ。長くいると構想が増える。装置を動かし、正確さ → 使いにくさ → 好みの順に直す |
| Level 3 | 熱い配管室 | 証言台の札を原文にあたって(確かめる)から「本人の言葉」「くり返し」「AIの解釈」の皿へ。確かめずに置こうとすると〈もっともらしい顔〉が現れる。文字おこしの機械は、目的の札を動かさずエンジンを替え、何度か試したら一式を畳んで(「やめときます。」)オンラインのAPIへ |
| Level 4 | 方法論のオフィス | 円の図を三つ以上、語数の秤、報告書の最終ページを見て、ペンで余白に書き足す |
| 出口 | 四つ目の鏡 | かけら三つで布が落ち、気持ち・人との時間・休み方・楽しみ・自分への点数の五つの欄を「書く」か「伏せる」。書いた中身はどこにも保存されない |

「正気度」は、黄色い部屋をさまよう、確かめずに信じかける、熱い配管にさらされる、などで減る。
0 になっても死にはせず、三面鏡の部屋(まだ行っていなければ黄色い部屋)で目を覚ます。
前の版(夜の観測所)の途中データは読まず、はじめからになる。

## 遊び方

- claude.ai のページ(本人だけが開ける。Chrome の「ホーム画面に追加」でアプリのように起動できる)
- Tasker のシーンで遊ぶときは `mirror-zork-standalone.html` を Webビューで開く。
  手順は `zork-ja/README.md` の「Tasker のシーンで遊ぶ」と同じで、置き場所だけ変える。

```bash
mkdir -p /storage/emulated/0/Tasker/mirror-zork
cp /storage/emulated/0/Download/mirror-zork-standalone.html /storage/emulated/0/Tasker/mirror-zork/mirror-zork.html
```

Webビューの「電話へのアクセスを許可」をオンにすると、途中の状態が
`Tasker/mirror-zork/mirror-zork-data.json` に残る(Tasker の変数 `%MIRRORZORK` も使う)。

## 確認できていること・いないこと

- 開発環境の Chromium(スマホの画面サイズ)で、黄色い部屋から三つのかけらを集めて脱出するまで通しで遊べた。正気度が 0 になったときの戻り先も確かめた。
  「命令を作る」・日本語の命令・英語の命令・続きから再開が動いた。
- Tasker の実機と claude.ai の中では、まだ確かめていない。
