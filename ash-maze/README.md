# 灰の迷宮（ash-maze）

初期のウィザードリー風の3D迷宮RPG。Tasker のシーンに WebView を1つ置き、その中で動かす。
ゲームは HTML 1枚（`ash-maze.html`、約130KB）だけでできていて、ネットにはつながない。

- 白い線で描く3Dの迷宮（一人称・正方形のマス目）
- 6人パーティ。前の3人が殴り合い、後ろの3人は呪文と道具
- 8職業（戦士・魔術師・僧侶・盗賊・司教・侍・君主・忍者）と転職
- 呪文は魔術・祈祷それぞれレベル1〜7、合わせて28種
- 地下10階。鍵の扉、隠し扉、暗闇、回転床、落とし穴、落とし戸、テレポーター、魔法の効かない場所
- 宝箱の罠（9種）を、盗賊が調べて外す
- 全滅すると遺体は迷宮に残り、別のパーティで回収する。寺院の蘇生は失敗すると灰に、灰からの失敗で消失
- 地図は自動で記録される
- 名前・敵・呪文・物語は、すべてこのゲームのために作ったもの（ウィザードリーの名前は使っていない）

## 物語

城の地下に広がる「灰の迷宮」。王の宝珠を奪った魔導師ヴァルガが、最も深い10階に潜んでいる。
宝珠を取り戻して町に持ち帰ると、エンディングになる（その後も遊び続けられる）。

3階・6階・9階には番人がいて、倒すと次へ進むための鍵が手に入る（4階・7階・9階の下り階段の手前に鍵の扉がある）。

## スマホに入れる

前提：Termux（F-Droid 版）で `termux-setup-storage` を済ませていること。

1. ブラウザで GitHub の `othermarrow/Claude` を開き、このファイルがあるブランチを選んでから
   `Code` → `Download ZIP` で zip を Download フォルダに保存する。
2. Termux で、取り出し用のスクリプトを作る（初回だけ）。
   `BR=` の後ろは、保存された zip の名前に合わせる（`Claude-main.zip` なら `main`）。

```bash
cat > ~/ash-maze-update.sh <<'EOF'
#!/data/data/com.termux/files/usr/bin/bash
# Download にある zip から ash-maze.html を取り出して、Download に置く
set -e
BR=main
ZIP=/storage/emulated/0/Download/Claude-$BR.zip
DST=/storage/emulated/0/Download/ash-maze.html
command -v unzip >/dev/null || pkg install -y unzip
cd ~
rm -rf "Claude-$BR"
unzip -o "$ZIP" "Claude-$BR/ash-maze/ash-maze.html"
cp "Claude-$BR/ash-maze/ash-maze.html" "$DST"
rm -rf "Claude-$BR"
echo "置いた: $DST"
EOF
chmod +x ~/ash-maze-update.sh
```

3. 実行する。新しい版の zip を保存したときも、これだけでよい。

```bash
bash ~/ash-maze-update.sh
```

`/storage/emulated/0/Download/ash-maze.html` ができる。

## Tasker で開く

（実機ではまだ試していない。Tasker の画面の言葉は、版や日本語訳によって少し違うことがある）

1. Tasker の「シーン」タブで「＋」を押し、名前を `灰の迷宮` にする。
2. シーンの編集画面で、シーンの枠を画面いっぱいまで広げる。
3. 要素を追加して「WebView」を選ぶ。
   - モード：URI
   - ソース：`file:///storage/emulated/0/Download/ash-maze.html`
   - JavaScript やファイルへのアクセスを許可する項目があれば、オンにする
     （ゲームは JavaScript で動くので、これがオフだと何も表示されない）
   - 要素の大きさも、シーンいっぱいに広げる
4. 「タスク」タブで新しいタスク `灰の迷宮を開く` を作り、アクション「シーン」→「シーンを表示」を足す。
   - 名前：`灰の迷宮`
   - 表示方法：「アクティビティ」の全画面のもの（Activity, Full Window など）
5. ホーム画面に、このタスクのショートカット（ウィジェット）を置くと、1回押すだけで始められる。

うまく表示されないときは、まずファイルマネージャーで `ash-maze.html` を Chrome で開いてみる。
Chrome で動けば、ゲーム本体は大丈夫で、Tasker の WebView の設定の問題。

## 記録（セーブ）

- 1歩ごと・行動ごとに、自動で保存する（WebView の保存領域 `localStorage`）。
- タイトル画面に「自動保存が使えないようだ」と赤い枠で出たときは、その WebView では保存が残らない。
  その場合は「町外れ」→「記録を書き出す（控え）」で出る文字を写してメモ帳などに貼っておき、
  次に遊ぶとき「記録を読み込む」に貼り付けて続ける。
- Tasker の JavaScript の関数（`tk.writeFile` など）が使えるときは、
  `Download/ash-maze-save.json` にも保存する。新しいほうを読み込む（これも実機では未確認）。
- 戦闘の途中で閉じると、次に開いたときは戦闘の前の迷宮の中から再開する。

## 遊び方

### 町

| 場所 | できること |
|---|---|
| 酒場 | パーティに入れる・外す・並べ替え（1〜3番目が前列）。善と悪は同じパーティに入れない |
| 宿屋 | 馬小屋（無料）は呪文が戻るだけ。客室（Lv×10G/人）はHPも全快。経験値がたまっていればここでレベルが上がる |
| 商店 | 売り買い、鑑定、呪いを解く（品物はなくなる）。売った掘り出し物は店に並ぶ |
| 寺院 | 麻痺・石化・死亡・灰を治す。死亡と灰は失敗することがある |
| 訓練場 | 冒険者を作る、おまかせで6人作る、転職、名前を変える、名簿を見る・消す |
| 町外れ | 迷宮に入る、記録の書き出し・読み込み |

### 迷宮

- 「▲前へ」「↰左」「右↱」「▼振り向く」で動く。3D の画面を押しても前へ進む。
- 「調べる」は目の前の壁を調べる。隠し扉が見つかることがある（盗賊がいると見つけやすい）。
- 「地図」は自動で記録された地図。行ったことのある階は切り替えて見られる。
- 「キャンプ」で呪文・道具・装備・並べ替え・鑑定。パーティ表の名前を押しても持ち物を見られる。
- 扉の奥の部屋には、たいてい番をする敵がいて、倒すと宝箱が出る（町に戻るとまた出る）。
- 宝箱は「罠を調べる」→「罠を外す」で、罠の名前を当てると外せる。僧侶の「罠見」の呪文はほぼ確実。

### 戦闘

- 前列の3人は「戦う」（敵の前の2組まで）、後列は呪文と道具。
- 僧侶（と、レベルの上がった司教・君主）は「解呪」で不死の敵をはらえる。
- 敵の名前は、最初は「動く骨」「ローブの男」のような見た目でしか分からないことがある。

### 職業

| 職業 | なるのに要る能力 | 性格 |
|---|---|---|
| 戦士 | 力11 | 善・中立・悪 |
| 魔術師 | 知恵11 | 善・中立・悪 |
| 僧侶 | 信仰11 | 善・悪 |
| 盗賊 | 素早さ11 | 中立・悪 |
| 司教 | 知恵12 信仰12 | 善・悪 |
| 侍 | 力15 知恵11 信仰10 生命力14 素早さ10 | 善・中立 |
| 君主 | 力15 知恵12 信仰12 生命力15 素早さ14 運15 | 善 |
| 忍者 | 全部15 | 悪 |

- 魔術師・僧侶は1レベルから呪文を覚え、2レベルごとに1段上の呪文を覚える。
- 司教は両方を覚えるが遅い。侍は4レベルから魔術、君主は4レベルから祈祷を覚える。
- 忍者は鎧と盾をつけないほど守りが固く、急所を突いて一撃で倒すことがある。
- 転職するとレベル1に戻り、能力値は種族の初期値に戻る。HP と覚えた呪文は残る。

### 呪文

| Lv | 魔術 | 祈祷 |
|---|---|---|
| 1 | 火矢（敵1体 1d8+1）・眠霧（1組を眠らせる） | 癒し（1d8+2回復）・加護（全員AC-1）・光弾（敵1体 1d8） |
| 2 | 惑い（1組の守りを下げる）・灯火（遠くと隠し扉が見える） | 沈黙（1組の呪文を封じる）・浮遊（落とし穴を避ける） |
| 3 | 火球（1組 3d6）・千里眼（周りの地図が分かる） | 解痺（麻痺と眠り）・罠見（宝箱の罠を見破る） |
| 4 | 氷嵐（1組 5d6）・鉄壁（全員AC-3） | 大癒し（3d8+6回復）・解毒 |
| 5 | 死の囁き（1組を即死）・雷鳴（全体 4d8） | 退魔（不死の1組を消す）・蘇生（死から。失敗で灰） |
| 6 | 業火（全体 6d8）・転移（行った階か町へ） | 全癒（全快・毒・麻痺・石化）・帰還（町へ。所持金半分） |
| 7 | 星落とし（全体 10d10）・時止め（敵が1回動けない） | 再誕（死・灰から全快で）・神罰（全体 8d8） |

### こつ

- 最初は厳しい。1階でも2〜3回戦ったら町に戻って休む。
- 魔術師の「眠霧」は、人や獣の群れによく効く（骨や死体には効かない）。
- 盗賊を必ず入れる。宝箱の罠で全滅することもある。
- 全滅しても名簿は残る。「おまかせで6人作る」で救助隊を作り、遺体を連れて帰って寺院へ。

## 作り直し・テスト

ゲームの元は `src/` にあり、`build.js` で1枚の `ash-maze.html` にまとめる。
`ash-maze.html` はリポジトリにも入れてあるので、遊ぶだけならビルドはいらない。

```bash
cd ash-maze
node build.js              # src/ → ash-maze.html
node test/maze_test.js     # 10階すべて、階段・鍵・番人の部屋に行けるか
node test/game_test.js     # 呪文・装備・呪い・宿屋・寺院・鍵・全滅などの仕組み
node test/sim_test.js      # 階ごとの戦闘の勝率（バランスの確認）
```

`test/ui_test.js`・`flow_test.js`・`deep_test.js`・`boss_test.js` は、Playwright でブラウザを動かすテスト
（Claude の作業環境で実行した。Termux では動かない）。
スマホの画面の大きさ（411×890）で、町の全機能、10階のボス、エンディングまで通ることを確かめた。
