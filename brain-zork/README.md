# 脳内バックルーム(brain-zork)

自分の頭の中を、地下へどこまでも続く黄色い部屋(Backrooms)として描いたテキストアドベンチャー。
見た目と操作は Zork 日本語版(`zork-ja/` のブラウザ版)と同じで、「命令を作る」と十字キーで遊べる。

## しくみ

- **手放した数だけ、深くなる。** 下の階へ行くには、その深さの「深み」(点検口・マンホール・井戸など)で、
  持っているものをひとつ手放す。給料袋、『嘘つき』という一言、正論、色見本帳、物差し、金塊の6つ。
- **雑念。** まぶしい街、うるさい色、くり返し、目が合うことで増える。10 になると、最後に「書いた」机の前で目を覚ます。
  机で「書く」と 0 に戻る。壁紙のお題、アメンボ、秋の桜、耳をふさぐことでも減る。
- **言葉。** あちこちの壁に貼られた「紙片」を読むと拾える(全部で28)。いちばん下の机で書くには 8 つ要る。
- **くり返し出てくるもの。** 「目をそらす」と開くもの(犬、ふすま)、名前をつけると「いる」に変わるもの(針金まんじゅう。
  名前をつけたあとはヒントをくれる)、少し後ろを歩いている「遅いほうの自分」(底で追いついてくる)。

## 素材

一つの文章を一つの階に割り当てず、考え方やモチーフを全体に散らした。文はそのまま使わず、言い換えている。

- Vault の `zork用/` に集めた、自分で書いてきた文章や物語。投稿先のサイト名やペンネームなどの固有名詞は出していない。
  - 書くことで頭の雑音が静まる／お題／最後の句点まで書く／何度も見た夢と、手放した数だけ重なる深さ
  - 夜勤の冷凍倉庫とアメンボ、ゴミピットと金色の雪、前世の貸金庫と金塊
  - 目が合うのは脅し、みんなそんなにこちらに興味はない、ていねいな言葉ほど重い、『嘘つき』という刃物
  - 消えない重い考えに名前をつける(外在化)、ふすまの奥の座敷牢、視野が狭くなると「行き止まり」に見える
  - 埃は見たままの色、注文どおりの「スミレ色」、上手に真似る鳥と下手でも練習を続ける鳥
  - 二百段を走って上る(同じことをくり返して違う結果を待たない)、こっそり公園を塗り直す、報酬とコスト
  - 変われとは言わない、秋にも桜はある、記憶が消えても記録は残る、二人の自分の歩く速さ
- Vault の `emptybox.md` の独り言と、幻覚を「出所の判断エラー」として捉えたメモ。
- Vault のごみ箱にあった随筆(上田で育ち、京都で「木曽路」とあだ名をつけられた話)。
- Claude の振り返り(確かめてから信じる、目的は変えずに手段を替える、合わなければ「やめときます。」)と、
  3つの AI に書いてもらった人物像(館の「三枚の肖像画」。1枚だけ、あなたがどこにもいない)。
- Claude の記憶にある道具(Xperia、Termux、リングが重なる時計の文字盤)。
- 使っていないもの: `心理学/` と `Abstract/` のフォルダ、`仕事用` フォルダの中身、施設の利用者さんが分かること。

## 深さ

| 深度 | 場所 | 手放すもの |
|---|---|---|
| 0 | 黄色い部屋(お題の壁紙) | なし(東へ三つ進むと床が抜ける) |
| 1 | 夜勤のロッカー室・夜明けの搬入口・ゴミピットの管制室 | 給料袋 |
| 2 | 影のない大通り・言葉の森・目の合う路地 | 『嘘つき』 |
| 3 | 木曽路の坂・川べりの並木・館の前庭・壁が作品の館・ふすまの奥の座敷牢・車のない地下ガレージ | 正論 |
| 4 | 色のうるさい画材室・音のない白い部屋・夜明けの音の部屋 | 色見本帳 |
| 5 | 二百段の階段・丘の上の公園 | 物差し |
| 6 | 行き止まりの部屋・白い天井の部屋 | (日誌で書き分けると道が開く) |
| 7 | 貸金庫の通路 | 金塊 |
| 8 | 底 | ― 机で「書く」と終わる |

上の階へはいつでも戻れる(十字キーの「上」)。前の版(Level 0〜13)の途中データは読まず、はじめからになる。

## 遊び方

- claude.ai のページ: https://claude.ai/artifact/N77A16nBGL5Dt17AxDcwWz(本人だけが開ける。Chrome の「ホーム画面に追加」でアプリのように起動できる)
- Tasker のシーンで遊ぶときは `brain-zork-standalone.html` を Webビューで開く。
  手順は `zork-ja/README.md` の「Tasker のシーンで遊ぶ」と同じで、置き場所だけ変える。

```bash
mkdir -p /storage/emulated/0/Tasker/brain-zork
cp /storage/emulated/0/Download/brain-zork-standalone.html /storage/emulated/0/Tasker/brain-zork/brain-zork.html
```

Webビューの「電話へのアクセスを許可」をオンにすると、途中の状態が
`Tasker/brain-zork/brain-zork-data.json` に残る(Tasker の変数 `%BRAINZORK` も使う)。
