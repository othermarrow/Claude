# 脳内バックルーム(brain-zork)

あなたのものの考え方を、どこまでも続く黄色い部屋(Backrooms)として描いたテキストアドベンチャー。
見た目と操作は Zork 日本語版(`zork-ja/` のブラウザ版)と同じで、「命令を作る」と十字キーで遊べる。

## 素材

- Vault(othermarrow/Psychology)の `Abstract/report/` にある文献レポートの見出し
  (見通し支援、機能アセスメント、インフォーマルなアセスメント、愛着支援、キーパーソン支援、
  24時間以上続く多動の医学的評価 など)と、各レポートに共通する「一致点と対立点」「エビデンスの限界」
  「今後の展望」という構成。
- Vault の `zork用/` に集めた、自分で書いてきた文章や物語。文はそのまま使わず、考え方と
  決めぜりふだけを借りて書き直した。投稿先のサイト名などの固有名詞は出していない。
  - 「できる」は、楽にできるのと死に物狂いでできるのを同じ顔にしてしまう
  - 消えない重い考えに名前をつけると、「ある」から「いる」に変わる(外在化)
  - 二百段の階段を走って上ると、三つ目の踊り場から上が見える(同じことをくり返して違う結果を待たない)
  - こっそり公園を塗り直す。誰も気づかないし、みんなそんなにこちらに興味はない
  - 埃は灰色ではなく、見たままの色をしている／注文どおりの「スミレ色」と本物のスミレ
  - 変われとは言わない。育てば変わる／秋にも桜はある
  - 上手に真似る鳥と、下手でも練習を続ける鳥が、同じ森で縄張りを重ねている
  - 見つめると閉じるふすま(目が合うのは脅しになる)
  - 「ここから先は行き止まりです」は本当か
  - エンディングのない世界で、今の一回分を生きる／最後の句点まで書く
- Vault の `emptybox.md` の独り言(「感情を喜怒哀楽に分ける時点でどうかしてる。」など)と、
  幻覚を「出所の判断エラー」として捉えたメモ。
- Vault のごみ箱にあった随筆(上田で育ち、京都で「木曽路」とあだ名をつけられた話)。
  つらい場面をそのまま描かず、「自分がどこから来たかは自分が知っていればいい」という形にした。
- MultiRing ウォッチフェイス(重なる予定は別のリングに入れれば両方見える)。
- Claude の振り返り(確かめてから信じる、目的は変えずに手段を替える、合わなければ「やめときます。」)と、
  3つの AI に書いてもらった人物像(Level 9 の「三枚の肖像画」。1枚だけ、あなたがどこにもいない)。
- 使っていないもの: `心理学/` と `Abstract/catalog/` のフォルダ、`仕事用` フォルダの中身、
  施設の利用者さんが分かること。

## 階層

| 階層 | 場所 | 元になった考え |
|---|---|---|
| Level 0 | 概観の黄色い部屋 | どのレポートにもある見出しの並び |
| Level 1 | 見通しの倉庫 | 見通し支援(置くだけでは働かない)。水たまりのアメンボ |
| Level 2 | 機能の配管 | 機能アセスメント(機能は固定した属性ではない)。「できる」の圧力計 |
| Level 3 | 代理報告の電話室 | インフォーマルなアセスメント。事実と主観を分ける |
| Level 4 | 待合室(安全地帯) | 愛着支援・キーパーソン支援(安全基地)。「行き止まりです」の貼り紙 |
| Level 5 | 除外診断の病棟 | 医学的評価(既存の診断が原因探索を止める) |
| Level 6 | 感覚遮断の白い部屋 | 幻覚は「出所の判断エラー」で、多くは健康な反応 |
| Level 7 | 木曽路の坂 | 上田と京都の随筆(正論は笑いの種にしかならない) |
| Level 8 | 同心円の時計塔 | MultiRing ウォッチフェイス(重なる予定を別のリングへ) |
| Level 9 | 壁が作品の館 | 書いてきた文章の断片、三枚の肖像画、見つめると閉じるふすま |
| Level 10 | ふすまの奥の座敷牢 | 重い考えに名前をつける(「ある」から「いる」へ)。選べる道は思ったより多い |
| Level 11 | 二百段の階段・丘の上の公園 | 走って上る(手段を替える)。こっそり塗り直す |
| Level 12 | 色のうるさい画材室 | 感覚の過敏とサングラス。埃は見たままの色 |
| Level 13 | 川べりの並木 | 変われとは言わない。秋にも桜はある。重なる縄張り |
| 出口 | 「今後の展望」の扉 | 各レポートの「今後の展望」 |

十二の断片(スケジュールカード・機能の札・観察ノート・あたたかい鍵・身体のカルテ・出所の札・
上田の地図・同心円の文字盤・名札・ペンキのはけ・色のついた埃・桜の落ち葉)を扉に入れると脱出できる。
Level 0 で西へ三つ続けて進むと木曽路の坂へ、東へ三つで見通しの倉庫へすり抜けられる。
「正気度」が 0 になっても死にはせず、待合室(まだ行っていなければ黄色い部屋)で目を覚ます。
この版から保存の形が変わったので、前の版の途中データは読まず、はじめからになる。

## 遊び方

- claude.ai のページ: https://claude.ai/artifact/N77A16nBGL5Dt17AxDcwWz(本人だけが開ける。Chrome の「ホーム画面に追加」でアプリのように起動できる)
- Tasker のシーンで遊ぶときは `brain-zork-standalone.html` を Webビューで開く。
  手順は `zork-ja/README.md` の「Tasker のシーンで遊ぶ」と同じで、置き場所だけ変える。

```bash
mkdir -p /storage/emulated/0/Tasker/brain-zork
cp /storage/emulated/0/Download/brain-zork-standalone.html /storage/emulated/0/Tasker/brain-zork/brain-zork.html
```

Webビューの「電話へのアクセスを許可」をオンにすると、途中の状態が
`Tasker/brain-zork/brain-zork-data.json` に残る(Tasker の変数 `%BRAINZORK` も使う)。
