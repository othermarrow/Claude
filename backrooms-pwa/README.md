# 階層目録

Backrooms のテキストアドベンチャーと、書き下ろしの和風ホラー「蔵守」と、心理学のノートと支援の資料から組んだ「控室」を、起動画面から選んで遊べるようにしたアプリ（PWA）。
Chrome で「インストール」すると、ホーム画面のアイコンから開ける。記録 01・02 は、もとの版より階層を深く、難しくし、目的が分からないように作り直している。記録 03 は、利用者の物語をもとに新しく作った。記録 05 は「夜の書庫」から移した。演出は、階層ごとに画面全体の色が変わり、走査線・ネオンの格言・背景の線画・bytebeat の音・揺れ・振動が出る。

## インストールのしかた（スマホだけでできる）

PWA は `https://` か `http://localhost` で開いたときだけインストールできる。リポジトリが非公開なので、Termux の中で小さなサーバーを動かして、同じスマホの Chrome から開く。

1. Termux で、`main` を取ってきてサーバーを動かす。

   ```sh
   cd ~/Claude
   git checkout main
   git pull origin main
   sh backrooms-pwa/serve.sh
   ```

   「Chrome で http://localhost:6060/ を開いてください」と出たら、Termux はそのままにしておく。

2. Chrome で `http://localhost:6060/` を開く。
3. 起動画面の「ホーム画面にインストール」を押す。ボタンが出ないときは、Chrome 右上の ⋮ から「アプリをインストール」または「ホーム画面に追加」を選ぶ。
4. インストールが済んだら、Termux のサーバーは Ctrl+C で止めてよい。一度開いたファイルはアプリの中に取っておかれるので、次からはホーム画面のアイコンだけで開ける（はず。下の「確認したこと」を参照）。

### 新しい版にするとき

手順 1 をもう一度やり、サーバーが動いているあいだにアプリを一度開く。開くたびにまずサーバーから新しいファイルを取りにいき、取れなかったときだけ取っておいたものを使う作りになっている。

### 注意

- 遊んだ記録は、Chrome の中の `localhost:6060` という場所に保存される。ポート番号（6060）を変えると、記録が見えなくなる。
- Chrome の「サイトのデータを削除」をすると、記録も消える。
- `serve.sh` は `127.0.0.1` でだけ待つので、同じ Wi-Fi のほかの端末からは見えない。


### 番号が 8080 から 6060 に変わった（記録の引っ越し）

ミナモ（9090）や端末の中の AI（8090）と離すため、既定の番号を 8080 から **6060** に変えた。Chrome は記録を番号ごとに分けて持つので、前に 8080 で遊んでいた記録は、一度だけ引っ越す（8080 の記録は消えずに残る）。

```bash
cd ~/Claude/backrooms-pwa
sh serve.sh 8080 &
sh serve.sh
```

1. 一行目は前の番号 8080 のサーバー（後ろで動く）、二行目が新しい番号 6060 のサーバー。
2. Chrome で `http://localhost:8080/move.html` を開き、「引っ越す」を押す。新しい番号の画面が開いて「受け取りました」と出れば、終わり。
3. 前の番号のサーバーを止める：`pkill -f "http.server 8080"`。ホーム画面の古いアイコンは消して、`http://localhost:6060/` でインストールし直す。
4. 古いアイコンを消すのは、引っ越しが済んでからにする（消すときに、8080 の記録も消すかを聞かれることがある。先に 6060 へ運んでおけば、どちらを選んでも 6060 の記録は残る）。

## 設定

起動画面の下に「音」「振動」「動き」の切り替えがある。3本のゲームでも同じ設定が使われる（localStorage の `bpwa.settings`）。「動き」を切ると、揺れ・明滅・背景の動きが止まる。端末の「視覚効果を減らす」設定がオンのときも止まる。

### ゲームと起動画面の約束

- 保存：`localStorage["bpwa.<id>.state"]`（id は `noclip` `yacho` `miteiko` `kuuran2` `kuramori` `hikae`）。蔵守の state は `game.export()` の JSON で、画面の文章は `bpwa.kuramori.log`、見た結末などは `bpwa.kuramori.loop` に分けて持つ。
- 札に出す要約：`localStorage["bpwa.<id>.meta"]` に `{"endings": [...], "total": 数, "deepest": "Level 11", "runs": 数, "updated": 時刻}`。
- 各ゲームの ≡ メニューに「起動画面へ」がある。

### fx.js の使い方（ゲームを直すとき）

`FX.level(階層, {a, b, mode, bed})`（`{hum: 0}` だけを渡すと無音）、`FX.bed(環境音)`、`FX.sfx(効果音)`、`FX.flicker(回数)`、`FX.stress(0〜1)`、`FX.shock(1|2)`、`FX.glitch()`、`FX.flash()`、`FX.blackout(ミリ秒)`、`FX.truism(英, 日, 出典)`、`FX.tags([...])`、`FX.vhs(true|false)`、`FX.align(true|false)`、`FX.vibrate(パターン)`、`FX.set("sound"|"vibe"|"motion", 真偽)`。どれも `window.FX &&` で守って呼ぶ。

`standalone/` の `*-standalone.html` は、演出（fx.js）を中に埋めこんだ一枚のファイル。サーバーなしで、ブラウザや Tasker のシーンで直接開ける（インストールはできない）。起動画面がないので「起動画面へ」ボタンは出ない。

## 野帳（強化版）

- もとの骨組み（出会うものを観察して野帳に書く、観察 → 見立て → 確かめる、渇きとけが、記録・椅子・記録の外などの結末）を残したまま、Level 0〜7 に Backrooms Wiki の設定を足し、Level 8〜11 と JP Wiki の 433 N（カプセルホテル）・444 N（夕暮れの田園）をつないだ。
- 全体をつなぐ糸として「星の紙片」が14枚ある。前にこの道を歩いた誰かの帳面からちぎれたページで、読むと野帳に写される。書き手が誰かは、どこにも書いていない。
- 増えた仕組み：穴の部屋、照明の消えた区画、B.N.T.G. の出店、工事の黒い影、九番道の標識、白い蛾、肉食の風船、霧、パーティーゴアー、五台の読み取り機、灯りの移るカプセル（433 N）、8手ごとに流れる夕方の放送（444 N）。
- 音は fx.js にまとめた（ゲーム独自の音源は外した）。部屋ごとに環境音が変わり、新しい記録・見立て・確かめ・実体の前ぶれ・結末に効果音が鳴る。渇きやけがで鼓動が速くなる。タップの音はなく、足音もごく一部の場面だけ。
- 結末は17。どれが正解かは書いていない。

- 記録：観察室の記録計が、あなたのふるまいを B の欄に、事実と解釈をまぜて一行ずつ書く（従ったとき、「わからない」と言ったとき、倒れたとき、決めつけを書いたときなど）。4 行で名前が「A」になり、右上に名札が浮かび、「にじみ」（ラベルの字の群れ。人ではない）が地下を這いはじめる。8 行で、ふつうの動詞が症状の言葉で書かれはじめる。12 行で結末。観察室でペンを使うと、B の欄の解釈を仮説の欄へ移して書き直せる（1 行減る）。
- ブース：壁の向こうの人は、ことばを使えず、ノックで何かを伝えている。待つと、その前に何があり（A）、何をして（B）、そのあと何が変わったか（C）が記録用紙にたまる（ペンが要る。起きなかった場面も残る）。四つの機能（逃避・注目・要求・感覚）から見立てを仮説カードに書き、条件を一度に一つだけ変え、判を押す（維持・修正・保留。「確定」の判はない）。機能は遊ぶたびに変わる。罰の動詞（扉を押さえる・受け渡し口を閉める・「静かに」）は廊下の明かりを落とし、決めつけ（わざと・気を引きたいだけ・問題行動）を書くと記録が重くなって、にじみが生まれる。
- 札：白い札にペンで字を書くと札になる（「休憩」「よんで」「もう一度」「おわり」「引く」）。受け渡し口に入れる札は、伝える手段そのもの。
- 表示と手がかり：取っ手と合わない「押」の札（はがすか、「引」の札を重ねて貼る）、浴室の絵の札の物置、片方の取っ手に手の届かない「二つの扉」（届くようにするか、選ばない）。
- 合図の音：地下二階で、短い音のあとに揺れが三度来る。そのあとは音だけで体がすくみ、前へ進もうとすると来た道へ戻ってしまう。音のあとで動かずに待つと、二度で消える。
- 地上への扉：はじめは何度押しても開かない。あとで（切れ端が四つそろうか、聴く部屋の左の声を聞いたあと）は、試せば開くが、何も知らせない。
- 受付：選んだ写真のすり替え、止まる笑顔、遮られたあとの人の入れ替わり。気づいたときだけ先へ進む。
- 「わからない」：鏡の向こうの小さな声が答えるが、そのたびに記録が一行増える（10 行からは答えない）。
- 演出：区画ごとの配色と環境音、格言（音なし）、揺れ・暗転・閃光・ちらつき、観察室と監視室と記録が重いときは記録映像の見た目（REC）。出来事の音はタップから 0.34 秒遅らせて鳴らし、タップそのものには音をつけない。足音は、はじめて着く階段・ブース・地上への扉だけ。
- 遊び方の説明は操作だけ。結末は 7 つで、どれが正解かは書いていない。
- ゲーム本体は `// ==== ENGINE BEGIN ====` 〜 `// ==== ENGINE END ====` の中にあり、画面・window・localStorage・navigator・FX に触らない（時計版にするとき用）。

### 素材の使い方

- 心理学のノート（`心理学/23_実験`・`21_理論`・`22_心理療法`・`30_文献`）：煙の待合室（1968）、暗い部屋の止まった光（1936）、段階的な目盛りと「続けてください」の声（1963。答える人はいない）、まれな跳躍の見張り（1948）、左右の耳に別の声・名前への気づき・雑音で消えた音の補い（1953・1959・1970）、言葉の一覧と、読まれなかった言葉（1995）、写真のすり替え（2005）、遮られたあとの人の入れ替わり（1997）、止まる笑顔（1978）、音と揺れの組み合わせ（1920。消去の手続きがなかったこと）、照明の報告書の食い違い、ゴム手袋の手（1998）、検査冊子の「用途」が版ごとに「支援 → 選別 → 隔離」と変わる歴史、診断ラベルのあとで、ふつうの動詞が症状の言葉で書かれること（1973）、曝露（待つと、すくみが消える）、外在化（ラベルは人ではない。書き直すと小さくなる）、ただ「居る」こと。実験の研究者の名前は、結末「事後説明」でだけ明かす（名前と年はノートに書いてあるとおり。資料室の検査冊子の初版にだけ、ビネとシモンの名がある）。部屋の索引カードには、年と手続きだけを書いた。各ノートの倫理の節（目的と方法の説明・任意・撤回・危険と利益の釣り合い・秘密・事後説明・弱い立場の参加者への保護）を、七つの切れ端にした。
- 行動支援の資料（`Support/`）：ABC 記録（事実と解釈を分ける・起きなかった場面も残す）、四つの機能の見立て、仮説の維持・修正・保留（確定しない）、一度に一つだけ条件を変える、罰ではなく先行条件と結果を変える、代わりの伝え方の札（休憩・よんで・もう一度・おわり）、アフォーダンスとシグニファイア（嘘の表示、見せかけの二択）、感覚（蛍光灯の瞬き）、見通し（時間が「適宜」としか書かれない予定表）、支援者の疲れは構造の問題（休みなく弾きつづけるピアノ、交代のない監視）、記録で人を評価しないこと（助けを求めると「依存的」と書かれ、それを書き直す）、二冊の記録の照合（「減少」が続く冊と、同じ日から白い「活動」の冊）。施設そのものは舞台にせず、支援の現場の具体（施設名・職員・利用者・事例）は出していない。
- 物語の束：題名・名前は出さず、像だけを言い換えて混ぜた。「私は〔　〕です」を埋めるたびに自分が物になっていく書式、嘘の貼り紙の下の鉛筆の書き置き、分量が全部「適宜」の手順、壁の向こうで休みなく弾きつづける演奏、「出なさい」ではなく「出てもよい」の緑、ずっと同じ午後の空の写真、ガラス板で正面を向かされる被写体（長椅子が鏡のほうを向いていること）、検査中に背中に触れる見えない手、空の椅子に誰かが写る画面、意味を知らずにいた記号が自分の名前だったこと、札だけ差し替えると意味が変わる場面。殺人・自殺・自傷・性暴力・虐待が中心の作品、実在の事件をなぞった作品、福祉施設や支援の現場に近い作品は使っていない。ほかのゲームで使った像（古い家・番号の廊下・白い部屋・記録係・公衆電話・鍵穴・山羊など）は避けた。

## 確認したこと

- 空欄_2：Playwright（Chromium、幅 390〜412px）で、6つの結末すべてに命令だけでたどり着けること、五つの欄が自分の字で埋まること、倒れたあとも翌朝から続けられること、ランダムな命令 約 50,000 回で例外が出ないこと、fx.js が読めなくても遊べることを確かめた（このあとで復活させたので、この版では結末だけ通し直す）。

- 起動画面：Playwright（Chromium、幅 390px）で開き、エラーが出ないこと、Service Worker が登録されること、オフラインでも開けること、Chrome がインストールできると判定すること（試験用の画面ではシークレット扱いになるので、その理由だけが出た）を確かめた。
- ノークリップ：6つの結末すべてに命令だけでたどり着けること（道筋を変えて各結末 250〜300回）、18種類の失敗に前ぶれがあり続けて遊べること、ランダムな命令 75,000 回以上で例外が出ないこと、ゲーム本体（ENGINE）が画面やブラウザの機能に触らないこと、古い保存が壊れないことを確かめた。
- 未定稿：Playwright（Chromium、幅 390px）で、5つの結末すべてに命令だけでたどり着けること、暗闇で消される・弁の順を間違える・願いを口にする・壁をすり抜ける・立入禁止の扉・小部屋に閉じこめられるなどの失敗のあとも遊び続けられること、回収人が盗んだ物が古本の部屋に移ること、ランダムな命令 72,000 回（地上・地下・箱・各層から始めて）で例外が出ないこと、fx.js がなくても遊べること、起動画面の札に結末の数と最深の層が出ることを確かめた。
- 野帳：17の結末と 433 N・444 N を通る道筋（20通り）に命令だけでたどり着けること、23種類の失敗に前ぶれがあり続けて遊べること、ランダムな命令 130,000 回で例外が出ないこと、時計版の切り出し（`yacho-watch/tools/build-engine.js`）がこの版でもエラーなく動くことを確かめた（時計版は今も `yacho/yacho.html` から作っている）。
- 蔵守：夜の書庫の攻略手順を、ここに写した `games/kura/*.js` で通し、8つの結末すべてに命令だけでたどり着けること、ランダムな命令 約 67,000 回（日本語の入力・ひとつ戻す・保存と続きの往復 約 800 回をまぜて）で例外が出ないことを確かめた。Playwright（Chromium、幅 360・390・412px）で、起動画面に札が5枚並ぶこと、蔵守の札から入って、命令を作る・入力欄・十字キー・ひとつ戻す・ヒント・メニューで遊べること、再読みこみで続き（状態と画面の文章）が戻ること、画面の口から8つの結末すべてにたどり着き、札に「結末 8 / 8」「最深 底の社」が出ること、画面の口でのランダムな命令 6,000 回（再読みこみ 20 回）でエラーが出ないこと、タップやキー入力の最中に音の出る呼び出し（効果音・揺れ・ちらつき・停電など）がないこと、横にはみ出さないこと、fx.js がなくても遊べること、オフラインでも開けること、HTML 一枚版がエラーなく開くことを確かめた。
