# 端末の夜（tanmatsu-watch）

Amazfit Balance 2 の中だけで動く、四話の短編集のミニアプリ（Zepp OS）。スマホとの通信はいらない。
『Stories Untold』の「古い端末で、話ごとに遊び方が変わる」という手ざわりを参考にした**オリジナル作品**で、話・人物・謎はすべて新しく書いた。

## あらすじ

冬。閉鎖された山の観測所に、あなたは一人で来た。二十年前の今夜、あなたはこの山で道に迷い、ここの無線に助けられた。
二階の当直室に残っていた古い端末に、フロッピーが四枚。

| 記録 | 題 | 遊び方 |
|---|---|---|
| 1 | 観測所 | 端末の中のテキストアドベンチャー。物 → したいこと、の順にタップする |
| 2 | 手順書 | 気象観測装置 KS-2 を、手順書（◀ 前／次 ▶ でめくる）のとおりに操作する |
| 3 | 周波数 | 受信機の目盛りを ±0.1 / ±1.0 で回して、放送を探す。近づくと手首が震え、雑音の中の言葉が読めてくる |
| 4 | 応答 | 無線で、あの夜の声に答える。1〜3 で知ったことを使う |

結末は五つ（よい結末が三つ、やり直しになる結末が二つ）。前の記録を終えると、次のフロッピーが入れられる。

## 画面

- 上から順に並ぶ。画面を上下にスクロールして使う。文字の入力はない（全部タップ）。
- 話ごとに画面の色が変わる（1 は緑、2 は琥珀、3 は水色、4 は赤）。
- 遊んでいる途中の「取り出す」で、フロッピー選びに戻る（その記録は、次に入れたとき頭から）。
- フロッピー選びの画面に「振動：入／切」と「はじめから」（3秒以内に2回押すと最初からになる）。

## 振動

電話が鳴る・記録紙が出る・放送に合う・結末で振動する。記録 3 では、合わせたい周波数の 0.1 手前で軽く、ぴったりで強く震える。
振動は `@zos/sensor` の `Vibrator` を使う。時計が対応していないときは、振動しないだけで遊べる。

## 保存

- 1手ごとに自動で保存する。アプリを閉じても、次に開くと続きから遊べる。
- 時計のアプリ用の場所に `tanmatsu.json`（状態）と `tanmatsu-set.json`（振動の入／切）を置く。アプリを消すと一緒に消える。

## 準備（初回だけ）

前提：Termux に Zepp OS の開発ツール `zeus` が入っていて、yacho-watch などを `zeus preview` で送れていること。

1. ブラウザで GitHub の `othermarrow/Claude` を開き、ブランチ `ccr-71fe1288-u1s0xg` を選んでから `Code` → `Download ZIP` で zip を Download フォルダに保存する。
   保存された名前は `ls /storage/emulated/0/Download/ | grep -i claude` で確かめられる（`(1)` が付くことがある）。
2. zeus を使っている環境（Termux、または Termux の中の root 環境）で次を実行する。zip の名前が違うときは `Claude-ccr-71fe1288-u1s0xg` の部分を書き換える。
   root 環境で `unzip` がないときは `apt install -y unzip` で入れる。

```bash
cd ~
unzip -o /storage/emulated/0/Download/Claude-ccr-71fe1288-u1s0xg.zip 'Claude-ccr-71fe1288-u1s0xg/tanmatsu-watch/*'
rm -rf ~/tanmatsu-watch
mv Claude-ccr-71fe1288-u1s0xg/tanmatsu-watch ~/tanmatsu-watch
rm -rf Claude-ccr-71fe1288-u1s0xg
bash ~/tanmatsu-watch/setup.sh
```

3. 時計とスマホをつないだ状態で、時計に送る。

```bash
cd ~/tanmatsu-watch
zeus preview
```

表示された QR コードを Zepp アプリ（開発者モード）で読み取ると、時計に入る。

## 補足

- `app.json` の appId `1098772` は仮の番号。時計に送るときに「ダウンロードエラー（400）」になったら、この番号が原因のことが多い。
  yacho-watch のときと同じく、Zepp 開発者サイトで発行した番号か、時計に入っている別のアプリの番号に変える。

```bash
cd ~/tanmatsu-watch
sed -i 's/"appId": 1098772/"appId": ここに番号/' app.json
```

- 竜頭を回して周波数を合わせる仕組み（`@zos/interaction` の `onDigitalCrown`）も入れてある。Balance 2 で効くかは未確認。効かなくても、ボタンで合わせられる。
- **実機ではまだ試していない。** パソコン上（Node.js）で Zepp OS の部品を偽物に差し替えて、
  ボタンだけで記録 1〜4 を通して、よい結末三つ（引き継ぎ・鏡・無名）まで遊べること、
  アプリを閉じて開き直しても続きから遊べること、
  ランダムなタップ 20 万回 × 4 通りで例外が出ず、四つの記録と二つのやり直し結末（沢・雪）に届くこと、
  ボタンが画面の幅からはみ出さないこと、保存が 1KB 前後に収まることを確かめた。
- 時計で、文字の大きさ・スクロール・速さ・振動に崩れがあれば直す。
